## 01｜研究で分かっていること：休み方の「正解」は、まだはっきりしない

まず、どのくらいある話なのか。

厚生労働省の「労働安全衛生調査」（令和7〈2025〉年調査）では、過去1年間に、メンタルヘルス不調で連続1か月以上休業した人が1人でもいた事業所の割合は10.8%でした。
これは「事業所の割合」です。
働く人の割合で見ると、メンタルヘルス不調で連続1か月以上休業した人は0.6%でした。
（常用労働者10人以上の民営事業所が対象で、1か月未満の休みは入っていません）

「働く人の1割が休職している」という意味ではないので、ここは間違えやすいところです。
ただ、職場で「休職」という言葉が出ること自体は、そこまで珍しい話ではなさそうです。

次に、休み方の研究。

海外の研究では、「全部休む（全休）」と「時間を減らして働きながら休む（部分休）」を比べたものがあります。
ノルウェー公衆衛生研究所の2018年の報告書（マッピングレビュー）は、こうした研究を13本集めていますが、ランダムに分けた試験（RCT）は1本だけで、残りは登録データを使った観察研究でした。著者自身が「部分休の効果について確かな結論は出せない」と書いています。

その1本のRCT（フィンランド）は、筋骨格系の不調（腰や肩など）の人が対象で、うつの人の研究ではありません。
精神疾患のある人を調べたデンマークの観察研究（Høgelund ほか 2012）では、部分休にしても、通常の勤務時間に戻るまでの期間は変わりませんでした。
著者は、部分休だけでは足りず、職場の取り組みや本人に合わせた支援と組み合わせることを示唆しています。

もうひとつ。
うつのある人の復職について、Cochrane のレビュー（2020）では、職場に向けた取り組みと治療などを組み合わせると、休職日数はおそらく減る、とされています。ただし、職場に向けた取り組みだけでは、ふだんの職場の対応より効果があるとは言えませんでした。
その後のレビュー（Brämberg ほか 2024、Tingulstad ほか 2022）も、職場が関わる復職支援には一定の根拠があるものの、確実性は低めで、どの形がいいかははっきりしない、という方向です。

ここで大事な注意がひとつあります。
これらの研究は、ほとんどが北欧やオランダのものです。
北欧などには「給付を受けながら時短で働く」部分休の公的な仕組みがあります。日本の休職とは仕組みが違うので、「日本でも部分休を選べる」とは言えません。

では日本はどうかというと、厚生労働省の「モデル就業規則」の解説に、こう書かれています。

「休職の定義、休職期間の制限、復職等については、労基法に定めはありません。」

つまり休職の制度は、会社ごとに就業規則で決まっています。
期間も、条件も、期間が終わったらどうなるかも、会社によって違います。

## 02｜問題提起：「休職」と言われた瞬間、決めなきゃいけない気がする

研究をまとめると、
「どの休み方がいいか」は、まだはっきりしていない。
しかも、日本では制度そのものが会社ごとに違う。

なのに、「休職」という言葉は、言われた瞬間に何かを決めることを求められているように聞こえます。

「休職になるかもしれない」
と言われたとき。
頭の中では、もう「休むか、辞めるか」の二択が始まっている。

でも、その時点で自分の会社の制度を知っている人は、たぶん多くないと思います。
期間は何か月なのか。時短や在宅のような、休職以外の形はあるのか。誰に何を聞けばいいのか。
それを知らないまま、一般論や誰かの体験談で決めてしまうのは、ちょっともったいない気がしています。

だから、この記事でいちばん言いたいのはこれです。
決める前に、確かめる。

## 04｜無料で持ち帰れる一言と、3つの枠

ここからは、この記事の提案です。

「休職」という言葉が出たら、その場ではこう言ってみる。

「一度、制度を確かめて、主治医とも相談してから返事をしてもいいですか」

そのうえで、確かめるのはこの3つだけです。

① 制度：休職の期間、条件、就業規則のどこに書いてあるか
② 選べる形：休職以外に、時短・在宅・業務の調整などの選択肢はあるか
③ 誰と話すか：上司・人事・産業医など、誰に何を聞けばいいか

全部を一度に聞かなくても大丈夫です。
まずは「その場で決めない」と「3つの枠」だけ持っておけば、少しだけ考える余白ができる気がしています。

## 05｜会社に確かめる質問リスト（コピー用）

まず、公的な資料に書いてあることから。

厚生労働省の「心の健康問題により休業した労働者の職場復帰支援の手引き」（2009年改訂）は、会社が休業から復職までをどう進めるかの目安として国が出している資料です。法律で決められた手順ではなく、すべての会社がこの通りに動いているわけではありません。
それでも、この手引きには、休業に入る人に会社が伝えるとよい情報として、
「傷病手当金などの経済的な保障」「不安、悩みの相談先の紹介」「公的または民間の職場復帰支援サービス」「休業の最長（保障）期間等」
が挙げられています。

つまり、ここから下の質問の多くは、聞いてもおかしくない項目です。
（厚生労働省のサイト「こころの耳」の社労士によるQ&Aでも、会社側に、就業規則の内容や休業中の決まりを書面にして渡すことが勧められています）

ここからは、この記事の提案です。
全部聞く必要はありません。気になる枠だけ使ってください。〔 〕は自分の状況に置きかえてください。

```
A｜制度
・休職の制度について書いてあるのは、就業規則（または社内規程）のどこですか？ 見せてもらえますか？
・休職できる期間は、最長でどのくらいですか？
・休職に入る前に、欠勤や有給休暇を使う期間はありますか？
・休職期間が終わっても戻れない場合、どういう扱いになりますか？
・休職に入るには、主治医の診断書が必要ですか？ 様式は決まっていますか？
```

```
B｜休職以外に選べる形
・休職の前に、時短勤務・在宅勤務・業務量の調整などを試すことはできますか？
・休職と、有給休暇やほかの休暇を組み合わせることはできますか？
・〔今の配慮〕を続けながら働く道は、もう難しいという判断ですか？ それはどこで決まりましたか？
```

```
C｜誰と話すか・情報の扱い
・この件の窓口は、上司・人事・産業医のどなたですか？
・産業医や保健師と話す機会はありますか？
・私の体調や診断の情報は、誰にどこまで共有されますか？
```

```
D｜休職中の連絡
・休職中の連絡の窓口は、どなたですか？
・連絡の方法（メール・電話・面談）と、だいたいの頻度は決まっていますか？
・体調が悪いときに連絡が遅れても大丈夫ですか？
```

```
E｜復職の流れ
・復職するとき、どういう手順になりますか？（主治医の診断書、面談、産業医の判断など）
・段階的に戻る仕組み（試し出勤、時短からの再開など）はありますか？
・戻るとき、同じ仕事・同じチームに戻る前提ですか？
```

```
F｜お金（ここは「どこで確かめるか」だけ聞く）
・休職中の給与や手当の扱いについて、どこを見れば分かりますか？
・傷病手当金を申請する場合、会社側の手続きはどうなりますか？
・休職中の社会保険料は、どう払う形になりますか？
```

お金の具体的な額や条件は、この記事では書きません。
傷病手当金は、加入している健康保険（保険証に書かれている保険者）で確かめてください。協会けんぽに入っている場合は、こちらのページに説明があります。
全国健康保険協会（協会けんぽ）「傷病手当金」 https://www.kyoukaikenpo.or.jp/g3/sb3040/r139/

就業規則の読み方や、法律上の扱いで迷ったら、専門家（社会保険労務士・弁護士など）に相談するのが確実です。

## 06｜聞く順番の分岐（この記事の提案）

ここは研究が示したものではなく、この記事の提案です。

会社から「休職」と言われた場合
1. その場では決めず、「制度を確かめて、主治医とも相談してから返事をしたい」と伝える
2. 就業規則（A）を見せてもらう
3. 主治医に、会社で言われたことをそのまま伝える
4. 休職以外の形（B）を聞く
5. ここまでそろってから、休むか・調整して続けるか・それ以外かを考える

自分から休むことを考え始めた場合
1. 先に就業規則を自分で確かめる（社内ポータルなどで見られることもあります）
2. 主治医に相談する
3. 誰に最初に話すかを決める（下の分岐）
4. 話すときは、AとBを中心に聞く

上司と話しやすい場合
→ 上司に最初に話して、人事や産業医につないでもらう

上司と話しにくい場合
→ 人事や産業医（いれば）に先に相談できるか、確かめる
→ 上司に何がどこまで伝わるか（C）を先に聞いておく

産業医がいる場合
→ 復職の流れ（E）は、産業医の関わり方まで聞いておく

産業医がいない場合
→ 小さな会社では、産業医がいないこともあります（選任が義務になるのは常時50人以上の事業場）。そのときは、人事や担当者に「誰が復職の判断に関わるのか」を聞く

手引きでは、主治医の「復職できる」という判断は、日常生活での回復をもとにしていることが多く、職場で求められる仕事ができるところまで回復した判断とは限らない、とされています。
なので、復職の流れ（E）は、休む前に一度聞いておくと、あとで慌てにくいかもしれません。

## 07｜その場で返事を求められたときの一言

この記事の提案です。言い回しは自分に合わせて変えてください。

```
・「大事なことなので、一度持ち帰って、制度を確かめてから返事をさせてください」
・「主治医にも相談したいので、〔　〕日までお時間をいただけますか」
・「休職の規定を、書面かリンクで共有してもらえますか」
・「休職以外に選べる形があるか、それも合わせて教えてもらえると助かります」
```

英語の職場向け

```
・"This is an important decision for me. Could I take some time to check the policy and talk to my doctor before I respond?"
・"Could you share the written policy on leave, so I can review it?"
```

（多分もっと自然な言い回しがあると思います。英語のメールにはAIも使うので、自分の言い方に直して使ってください）

## 08｜休職中の連絡を、休む前に決めておく

### 研究で分かっていること

- 「休職中の連絡は、多いほうがいい／少ないほうがいい」と言い切れる研究は、今回の調査では見つかりませんでした。連絡の頻度そのものを比べた研究もありませんでした。
- 精神的な不調などで休んでいる人の復職支援をまとめたメタ分析（Mikkelsen & Rosholm 2018）では、「職場との接点を含む取り組み」に強いエビデンスがある、と格付けされています。ただし、これは取り組みの要素の1つとしての格付けで、連絡の頻度や窓口を比べたものではありません。
- オランダで、よくある精神的な不調で休んだ人34人に話を聞いた研究（Joosen ほか 2022）では、準備ができていないのに復職を急かされたと感じたことが妨げとして語られ、急かさない・話を聞いてくれる上司が助けとして語られました。少人数の聞き取りの研究なので、どのくらいの人に当てはまるかは分かりません。
- 上司とのコミュニケーションと復職の関係を調べたオランダの研究（Nieuwenhuijsen ほか 2004）もありますが、関連が見られたのは抑うつ症状が強くない人で、症状が強い人では確認できませんでした。なので「上司とよく連絡を取れば早く戻れる」とは言えません。
- これらもオランダや北欧の研究で、日本の会社の休職にそのまま当てはめることはできません。

### 公的な資料に書いてあること

「こころの耳」の社労士によるQ&Aでは、会社側に、休業中の連絡の窓口・頻度・方法・内容を決めておくことが勧められています（実務上の助言で、効果を調べた研究ではありません）。

### この記事の提案：取り決めメモ

研究で分かっていることを合わせると、連絡の「量」より、「急かされない」「誰と、どうやって話すか分かっている」ほうが大事なのかもしれません。
なので、休む前に、次のメモを会社と一緒に埋めておくのはどうでしょう。
頻度は〔 〕にしてあります。何回がいい、という研究はないので、自分と会社で決めてください。

```
休職中の連絡の取り決め（休む前に確認）
・連絡の窓口：〔上司／人事／産業医・保健師〕
・連絡の方法：〔メール／電話／オンライン面談〕
・連絡の頻度：〔　〕（体調が悪いときは遅れてもよいか：〔はい／相談〕）
・連絡の内容：〔体調の様子だけ／手続きの連絡だけ／仕事の話はしない　など〕
・仕事の引き継ぎについて連絡が来る場合の窓口：〔　〕
・私の体調の情報を共有してよい相手：〔　〕
・復職を考え始めたときに、最初に連絡する相手：〔　〕
```

## 09｜面談の前に、AIで自分の質問を整理する頼み方

この記事の提案です。
注意：社名・人の名前・社内の資料や就業規則の本文は、そのまま貼らないほうが安全です（会社のルールがあれば、それに従ってください）。AIは制度や法律の答えを出すために使うのではなく、自分が何を聞きたいかを整理するために使います。

私は受診の前に、相談したいことをAIにまとめてもらって、診察で読んでもらうことがあります。
面談の前も、たぶん同じ形が使えると思います。

```
頼み方1：私に質問して
会社で「休職」という話が出ました。
面談の前に、自分が何を確かめたいのかを整理したいので、私に質問して。
質問は1回に1つ、全部で5つまで。
最後に、私が会社に聞きたいことを箇条書きにまとめて。
```

```
頼み方2：私はこう思ったんだけど、どう思う？
私は今、〔休む／調整して続ける／まだ決められない〕の方向で考えています。
理由は〔　〕です。
私はこう思ったんだけど、決める前に確かめておいたほうがいいことが抜けていないか、質問の形で教えて。
どれがいいかの判断はしないで。
```

```
頼み方3：質問リストを自分用に短くする
次の質問リスト（貼り付け）から、私の状況（〔　〕）で、最初の面談で聞くものを5つに絞る手伝いをして。
絞った理由も1行ずつ書いて。最終的にどれを聞くかは私が決めます。
```

## 10｜研究で分かっていること・分かっていないこと・この記事の提案

研究で分かっていること
- 全休と部分休を比べた研究は少なく、RCTは筋骨格系の人を対象にした1本だけ。精神疾患のある人の観察研究では、部分休で通常の勤務時間に戻るまでの期間は変わらなかった。
- 職場が関わる復職支援には一定の根拠があるが、確実性は低めで、どの形がいいかははっきりしない。
- 休んだ本人の聞き取りでは、急かされることが負担として語られている。
- 日本のIT企業1社でうつで休業して復職した人を追った研究（Endo ほか 2013）では、復職後にふたたび休業した人が少なくありませんでした。1社の研究で、一人ひとりの見通しを示すものではありませんが、休職は「休んで終わり」ではなく、戻り方まで含めて考える話なのだと思います。

公的な資料に書いてあること
- 休職は労働基準法に定めがなく、制度は会社ごとの就業規則で決まる（モデル就業規則の解説）。
- 会社が休業に入る人に伝えるとよい情報として、経済的な保障・相談先・復職支援サービス・休業の最長期間などが挙げられている（職場復帰支援の手引き。会社向けの目安）。

分かっていないこと
- うつのある人で、全休・部分休・休まずに調整して働く、の3つを比べた研究（今回は見つからなかった）。
- 休職中の連絡の頻度や、窓口の違いと復職の関係。
- 日本の働く人を対象にした、休職の形や休職中の連絡についての研究（今回は調べていない）。
- 「その場で決めずに確かめる」ことが、その後の結果をよくするか（調べた研究は見つからなかった）。

この記事の提案（研究の結論ではありません）
- 「休職」という言葉が出たら、その場で決めず、制度・選べる形・誰と話すか、の3つを確かめる。
- 質問リスト、聞く順番の分岐、連絡の取り決めメモ、AIへの頼み方。
- 期間や頻度の目安は、あえて入れていません。会社ごと・人ごとに違うので。

## おわりに

「休職」という言葉は、聞いた瞬間にかなり重いです。
休むか、辞めるか、続けるか。どれを選んでも、たぶん迷うと思います。

ただ、どの休み方がいいかは研究でもまだはっきりしていないし、制度は会社ごとに違う。
だとしたら、一般論で決める前に、自分の会社で何を選べるのかを知るところから始めてもいいのかもしれません。

決めるのは、確かめてからでも遅くない。
最近はそんなふうに考えています。
