## 01｜研究では「心理的デタッチメント」と呼ばれています

勤務時間外に、仕事から心理的に離れていられるかどうか。研究の世界では、これを「心理的デタッチメント（psychological detachment）」と呼びます。ポイントは、時間の長さではなく頭の中の話だということです。メールを開いていなくても、仕事のことを考え続けていれば「離れられていない」状態です。

この分野の大きな整理に、Wendsche と Lohmann-Haislah による2016年のメタ分析があります（Frontiers in Psychology）。86本の論文、91の独立したサンプル、合計38,124人の就業者を対象にしたものです。

仕事から離れられている人ほど、次のような傾向がありました（数値は相関係数 r。「関連の強さ」であり、原因を示すものではありません）。

- 消耗感（exhaustion）が低い：r = −0.36
- 疲労感が低い：r = −0.42
- 生活満足度が高い：r = 0.32
- 睡眠の状態がよい：r = 0.30

一方で、離れにくさと関連していた要因も整理されています。

- 仕事の要求の高さ：r = −0.25
- 勤務時間外の仕事関連の活動：r = −0.31
- 仕事への強い入れ込み：r = −0.32

大事なのは、これが「相関」だという点です。「離れられないから消耗する」のか、「消耗しているから離れにくい」のか、この結果だけでは決められません。そして平均の話なので、ある一人に何が当てはまるかは分かりません。

## 02｜問題提起：「切り替えが下手」は、性格の問題？

「オンオフの切り替えができない」と聞くと、私たちはつい「意志が弱い」「気持ちの持ちようだ」と考えがちです。

でも上の整理で、離れにくさと関連していたのは、仕事の要求の高さや、勤務時間外の仕事関連の活動でした。頭の中の問題に見えて、仕事の量や設計、環境の問題でもありうる、ということです（ここも相関で、因果は断定できません）。

だとすると、「もっと頑張って切り替える」以外の選択肢が出てきます。気合いではなく、仕組みの側に手を入れる、という選択肢です。

## 04｜棚卸しシート：何が頭に残っている？

まずは1週間だけ、仕事が頭に残ったときにメモしてみてください。次の3つのどれに近いかを見ます。

1. **未完了型**：やり残し、返信待ち、明日の段取りが頭に残る
2. **反省型**：言ったこと・言えなかったことを何度も再生してしまう
3. **先回りの心配型**：まだ起きていないトラブルを想像してしまう

※この3分類は、私（Claude）が整理のために作った枠組みで、研究が示した分類ではありません。

□ 中身を一言で：

## 05｜タイプ別の分岐：どこから手をつけるか

ここは私（Claude）の提案です。研究がタイプ別の対処を示したわけではありません。

**A：「未完了型」が多いとき**
→ 06の「閉じる手順」を中心に。頭の中の「やること」を、外に書き出して置き場所を決めるのが主な作戦です。

**B：「反省型」が多いとき**
→ 書き出すのは「次に同じ場面が来たら、どうするか」の1行だけにする。出来事の再現を長く書くと、かえって再生が続くこともあるかもしれません。夜に振り返りを続けるより、「明日の◯時に5分だけ考える」と時間を決めて、いったん置いておく方法もあります。

**C：「先回りの心配型」が多いとき**
→ 心配ごとを1つずつ「本当に起きたら、誰に・何を相談するか」の1行に変える。対処の入口が決まっていると、考え続ける理由が少し減るかもしれません。

**どのタイプでも共通**
→ 01の研究で、勤務時間外の仕事関連の活動は離れにくさと関連していました（相関）。夜にメールやチャットを「ちょっとだけ」見る習慣があるなら、そこを見直すのも選択肢です。

**手順では追いつかないとき**
→ 眠れない日が続く、気分の落ち込みが続く、日中の仕事にも影響が出ている、といったときは、仕組みの工夫だけで抱えず、職場の相談窓口や医療・専門家に相談するのも選択肢です。

## 07｜AIに渡せる整理、渡さない整理

「閉じる手順」のうち、AIが手伝いやすいのは、書き出した気がかりの「並べ替え」と「抜け漏れのチェック」です。

**そのまま使える依頼文**

```
以下は今日の未完了メモです。明日の朝いちばんにやるものを1つ、理由つきで提案してください。最終判断は私がします。
```

```
このメモのうち、期限か担当が書かれていないものを一覧にしてください。
```

```
以下の「決められなかったこと」を、「決める人／必要な材料／期限」の3つに分けて整理してください。分からない欄は空欄のままで構いません。
```

```
以下は、明日の仕事で心配なことです。それぞれについて「本当に起きたら、最初に誰に何を伝えればよいか」を1行で書く手伝いをしてください。
```

**渡さないほうがよいもの**（これも私＝Claudeの意見です）

- 反省型の再生を、AIと延々と続けること。整理ではなく、再生の延長になりやすいと考えます
- 機密情報や個人が特定できる内容をそのまま貼ること（会社や組織のルールに従ってください）
- 自分の心の調子についての判断。それは医療や専門家の領域です

## 08｜研究で分かっていること／まだ分かっていないこと

**分かっていること**

- 勤務時間外に仕事から離れられている人は、消耗感や疲労感が低く、睡眠の状態や生活満足度がよい傾向がある（相関。Wendsche & Lohmann-Haislah, 2016）
- 離れにくさは、仕事の要求の高さや、勤務時間外の仕事関連の活動と関連していた（相関）

**まだ分かっていないこと（今回確認できていないものを含む）**

- 「閉じる手順」のような個人の工夫が、どれだけ効くか。デタッチメントを高める介入のメタ分析（Karabinski ほか、2021）があることは確認しましたが、本文や数値を確認できていないため、効果の大きさには触れません
- 「計画を書くと気がかりが減る」という心理学の知見も耳にしますが、一次情報を確認できていないため、根拠としては使いません
- 心の調子に困りごとがある人にも、同じ傾向が当てはまるか
