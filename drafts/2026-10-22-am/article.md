# 「あとで返す」が溜まっていく人へ ― 未返信のメール・Slackを「仕分ける・一言で受け取る・あとで返す」に分ける仕組みと、研究で分かっていること（特性と私 #06）

こんにちは、セナです。

その場で返せなかったメールやSlackに、「あとで返そう」と思う。
夕方には別の仕事に流れて、次の日にはもう覚えていない。

数日後。

「先日の件、いかがでしょうか？」

と来て、気づく。

で、未返信が溜まるほど、受信箱を開くこと自体がちょっと重くなっていく。
そういうこと、ありませんか。

この記事は、「あとで返す」が溜まりやすくて困っている人に向けて書いています。
「もっと気をつける」「すぐ返す」の代わりに、「返す」を3つに分けて、1日の終わりにAIにも少し手伝ってもらう、という話です。

この記事で分かること

- 「返す」を「仕分ける・一言で受け取る・あとで返す」の3つに分ける考え方（無料部分）
- 相手の待ちを止める「受け取りの一言」の文例（有料部分）
- 1日の終わりに、AIに「受け取っただけ」の一覧と期日を作ってもらう手順（有料部分）

※この記事は医療の記事ではありません。ADHDの研究に触れますが、診断や治療の話はしません。気になることは主治医や専門家に相談してください。
※「研究で分かっていること」「この記事の提案（研究の結論ではありません）」「私の経験」を分けて書きます。
※ADHDの診断がなくても、返信は普通に溜まります。診断の有無に関係なく読めるように書いています。

## 01｜研究で分かっていること・分かっていないこと

先にまとめると、ADHDの大人の「メールやチャットの返信が遅れる・忘れる」を直接調べた研究は、今回探した範囲では見つかりませんでした。
なので、「ADHDだから返信を忘れる」とは言えません。

以下は、近いけれど別のことを調べた研究です。

### 「あとでやる」を覚えておくこと

予定した行動を、あとで思い出して実行する記憶のことを、展望記憶と呼ぶそうです。
「あとで返そう」は、まさにこれに近い。

大人のADHDの展望記憶については、小さな研究がいくつかあります（ここで紹介する3本は、どれも各グループ24〜45人くらいで、ドイツの研究が中心）。

- ある研究（Fuermaier ほか, 2013。ADHDの大人45人と比較群45人）では、差が一番大きかったのは「計画を立てる段階」でした（効果量 d = 1.60）。一方で、立てたプランを覚えていること自体は、どちらのグループも約86%正確で、差はありませんでした
- 別の研究（Altgassen ほか, 2014。25人ずつ）では、「◯分後に〜する」のように時間を手がかりに思い出す課題で大きな差があり、「〜が出たら〜する」のように出来事を手がかりにする課題では差がありませんでした
- 日常生活で「自分が立てた予定」を実行できた数が少なかった、という研究もあります（Altgassen ほか, 2019。29人と24人）

つまり、どの段階でつまずくかは研究によって違っていて、まとまった結論はまだありません。
研究をまとめたメタ分析も、見つかりませんでした。

あと、どれもメールの返信を調べたものではありません（実験の課題（朝食づくりのゲームや、10個の小さな課題）や、日常の予定の記録で調べたものです）。
平均の差なので、ADHDの人がみんな予定を忘れる、という話でもないです。

仕事全体の話だと、ADHDと診断された大人134人と比較群268人を比べたドイツの調査（Fuermaier ほか, 2021）で、「仕事を効率よく片づける」ことに困りを感じる人の割合が55.0% 対 11.7%でした。
ただこれも自己申告で、メールの項目はありません。

### 「すぐ返さなきゃ」は、相手の期待より強いかもしれない

こっちは、ADHDに関係なく、メールの研究です。

急ぎでない仕事のメールについて、受け手は「相手はもっと早い返信を期待しているはず」と、送り手の実際の期待より高く見積もりやすい、という実験研究があります（Giurge & Bohns, 2021。8つの研究、合計4,004人。主にアメリカの会社員が、想像の場面で答えたもの）。
特に、夜や週末など勤務時間外に届いたメールで起きやすく、勤務時間内の結果ははっきりしませんでした。

そして、勤務時間外に届いた場合で、送り手がメールの最後に「急ぎではないので、都合のよいときに対応してください」と一言添えると、このズレは小さくなりました。

ここ、大事なので書いておくと、効いたのは送る側の一言です。
受け取った側が「受け取りました、◯日までに返します」と返す一言は、この研究では調べられていません。
それから、調べたのはメールだけで、Slackなどのチャットは調べていません。

### 「すぐ返さなきゃ」という気持ちと、疲れ

仕事の連絡にすぐ返さなきゃ、という気持ちにとらわれることを、テレプレッシャーと呼ぶ研究があります（Barber & Santuzzi, 2015 が測り方を作った）。

フルタイムで働く233人に1回だけ調査した研究（Hu ほか, 2019）では、この気持ちが強い人ほど、身体の疲れや睡眠の質の悪さと関連していました。
ただ、関連は弱く、1回の調査なので、どちらが原因かは分かりません。

### メールを見る回数を決める

メールを見るのを1日3回に絞った週と、できるだけ頻繁に見た週を比べたカナダの実験（Kushlev & Dunn, 2015。124人が最後まで回答）では、3回の週のほうが1日のストレスが少し低めでした。差は小さめです。
その日の「生産性の実感」には差がありませんでした。

この研究で変えたのは本人がメールを見る回数だけで、周りの人の「すぐ返して」という期待は変えていません。
著者は、チームや会社の単位で期待を変えたほうが効果が出るかもしれない、と書いています。
ここは、あとの「一言で受け取る」の話と少しつながります。

### まとめると

- ADHDの大人の返信の遅れ・忘れを直接調べた研究は、見つからなかった
- 予定した行動をあとで実行することのつまずきは、小さな研究で報告されている。どの段階でつまずくかは研究によって違う
- 急ぎでないメールでは、受け手が「早く返さなきゃ」を強めに見積もりやすい。送り手の一言でズレは小さくなった
- 「すぐ返さなきゃ」の気持ちと疲れには、弱い関連がある（因果は分からない）

という感じでした。

## 02｜「すぐ返す」「もっと気をつける」を目標にすると

ここからは、研究の結論ではなく、この記事の考えです。

返信が溜まったとき、よく出てくる目標はこの2つだと思います。

「もっと気をつける」
「来たらすぐ返す」

でも、01を見たあとだと、どっちも少し無理があるように見えます。

「もっと気をつける」には、何をいつ思い出すかが入っていない。
「すぐ返す」は、そもそも全部のメールで必要なわけではなさそう（急ぎでないメールなら、受け手が思うほど、相手は急いでいないかもしれない）。

で、この2つを目標にすると、溜まったときに自分を責めるほうに行きやすい。
責めると、受信箱を開くのがもっと重くなる。
開かないと、もっと溜まる。

なので、「忘れない」より、「忘れても拾える仕組み」と「相手を待たせっぱなしにしない一言」のほうが、現実的なんじゃないか。
この記事では、そう考えています。

## 04｜無料で持ち帰れる軸：「返す」を3つに分ける

ここからも、研究の結論ではなく、この記事の提案です。

「返す」を1つの作業だと思うと、重い。
中身を考えて、文面を作って、送る、まで全部入っているので。

なので、3つに分けます。

1. 仕分ける
2. 一言で受け取る
3. あとで中身を返す

### 1. 仕分ける

来た連絡を、まず3つの箱のどれかに入れます。

- 返す（自分が答える・動く必要がある）
- 返さなくてよい（CCで共有されただけ、自動の通知、Slackならリアクションで足りるもの）
- 判断が要る（自分だけでは決められない、誰かに確かめてから）

「返さなくてよい」の箱を最初にちゃんと作っておくと、残りが少し減ります。

### 2. 一言で受け取る

「返す」と「判断が要る」の箱で、その場で中身を返せないものは、先に一言だけ返します。

例えば、こんな一文です。

「受け取りました。〔◯日〕までにお返事します。」

01の研究で効いたのは送る側の一言でしたが、この記事では、その「期待を言葉にする」考え方を、受け取る側に借りています（受け手の一言の効果は、研究ではまだ確かめられていません）。

相手の頭の中で「まだかな」が続くのを、こちらから止めにいく感じです。
自分にとっても、「あとで」が「〔◯日〕まで」に変わる。

### 3. あとで中身を返す

一言で受け取ったものは、「受け取っただけ」のものとして、どこかに残しておきます。
そして、先に決めておいたタイミングで見直す。

「あとで」を頭で覚えておくより、見直すタイミングを先に決めて、そこで拾うほうが楽だと考えています（これは提案で、研究で確かめたものではありません）。
タイミングは、「PCを閉じる前」のように毎日ある場面に決めておくと分かりやすいかもしれません（06で書きます）。

「◯◯のときに△△をする」と前もって決めておくと、やろうと思ったことを実行しやすくなる、というメタ分析はあります（Gollwitzer & Sheeran, 2006。一般の人が中心で、大人のADHDで試した研究は見つかりませんでした）。

## 05｜コピー用：「受け取りの一言」の文例

〔 〕の中は自分の状況に置きかえてください。

一言のコツは、だいたいこの3つです（目安）。

- 受け取ったことを言う
- いつまでに返すかを言う（決められなければ「いつまでに返すかを返す日」でもいい）
- 今できない理由は、長く書かない

それから、〔◯日〕は少し余裕を持った日にしておきます。
守れない日を書くと、それはそれで別の「まだかな」を作ってしまうので。

### 上司に

すぐ答えられないとき
```
ありがとうございます、受け取りました。
〔◯日〕までにお返事します。
```

判断に時間がかかるとき
```
ありがとうございます。
〔確認したいこと〕を確かめてからお返事したいので、〔◯日〕までお時間をいただけますか。
```

優先が分からないとき（量が多いとき）
```
受け取りました。
今〔A〕と〔B〕を進めていて、どちらを先にしたほうがよいか教えてもらえますか。
```

### 同僚に

すぐ答えられないとき
```
見ました！〔◯日〕までに返しますね。
```

担当が違うとき
```
ありがとうございます。
この件は〔担当の人〕のほうが詳しいと思うので、〔担当の人〕にもつなぎますね。
```

### 社外に

すぐ答えられないとき
```
ご連絡ありがとうございます。内容を確認いたしました。
〔◯日〕までにお返事いたします。
```

判断に時間がかかるとき
```
ご連絡ありがとうございます。
社内で確認のうえ、〔◯日〕までにご回答いたします。
```

### 英語で（少しだけ）

```
Got it, thanks. I'll get back to you by [day].
```

```
Thanks — I need to check [thing] first. I'll follow up by [day].
```

```
Thanks for the reminder, and sorry for the wait. I'll send it by [day].
```

3つ目は、催促されてから気づいたときの返しです（09の分岐4）。

【✏️要記入：セナさんがふだん使っている「受け取り」の一言があれば、1つ。（ガイド：日本語でも英語でも。使っていなければ「使っていない」でよく、その場合この欄ごと削除。社名・相手の名前は〔 〕に置きかえる）】

## 06｜1日の終わりの見直し手順（3ステップ）

1日の終わりに1回見直すことの効果を確かめた研究は、見つかっていません（01のメールの実験で調べたのは「1日3回に絞る」で、これとは別のことです）。

時間は5分くらいが目安です（研究で決まった数字ではありません）。

ステップ1：その日の「受け取っただけ」を拾う
→ 一言で受け取ったけれど、中身はまだ返していないものを一覧にします。07の頼み方1を使ってもいいし、自分で書き出しても大丈夫です。

ステップ2：期日を付ける
→ 相手が書いていた期日、自分が一言で約束した〔◯日〕を、元のメール・Slackで確かめて付けます。期日がないものは、自分で決める。

ステップ3：翌朝の最初にやる1件を決める
→ 全部を並べ替えなくていいです。1件だけ。

見直すタイミングは、「PCを閉じる前」「最後の会議のあと」のように、毎日ある場面に決めておくと分かりやすいかもしれません（これは提案で、研究で確かめたものではありません）。

急ぎ順に並べる頼み方と、終業前に頭を閉じる手順は、末尾の「次に読むなら」に置いています（ここでは繰り返しません）。

## 07｜コピー用：AIへの頼み方3つ

研究で効果が確かめられた頼み方ではありません。

前提を先に書いておきます。

- AIには、自分で短くまとめた要点を貼るだけにします。AIがメールやSlackを送ることはありません。送るのは自分です
- 社外秘の内容、顧客名、同僚の名前は貼らずに、〔相手A〕〔案件B〕のように置きかえます
- 社内の情報をAIに入れてよいか、どのAIを使ってよいかは、会社のルールが前提です。迷ったら、会社のルールや窓口で確かめてください

要点は、1件1行くらいで大丈夫です。

```
〔相手A〕メール：資料の確認依頼。「〔金曜〕までに」とあり。「受け取りました」だけ返した
〔相手B〕Slack：会議の日程の相談。期日は書いていない。まだ何も返していない
〔相手C〕メール：共有のみ（CC）
```

### 頼み方1：「受け取っただけ」の一覧と期日を作る

```
これは今日の仕事の連絡の要点です（自分でまとめたものです）。
次の3つに分けて、一覧にしてください。
・受け取っただけで、中身をまだ返していないもの
・まだ何も返していないもの
・返さなくてよさそうなもの（理由を一言）

それぞれに、要点に書いてある期日を付けてください。
期日が書いていないものは「期日なし」と書いて、推測で日付を入れないでください。
急ぎ順の並べ替えや、返信の下書きはいりません。

最後に、私に質問してください。
「期日なし」のものについて、自分でいつまでに返すかを決めるか、聞いてください。

〔要点を貼る〕
```

最後の「私に質問して」は、私がAIによく頼む形です。
分かっているつもりのことも、「なんで？」と聞かれると意外に答えられないので。
期日が「なんとなく今週中」のままだと、そのまま流れやすいので。

「推測で日付を入れないで」は、AIが書いていない期日を推測で埋めることもありうるので、先に止めておくためです。

### 頼み方2：期日を過ぎたもの・今日中のものだけ拾う

```
これは私の「受け取っただけ」の一覧です。今日は〔◯月◯日〕です。
次の2つに当てはまるものだけを抜き出してください。
・期日を過ぎているもの
・期日が今日か明日のもの
並べ替えやアドバイスはいりません。抜き出すだけにしてください。

〔一覧を貼る〕
```

### 頼み方3：「返さなくてよいか」の見分けを手伝ってもらう

```
下の連絡の要点について、私が返事をする必要がありそうかどうかを、
「必要そう／たぶん不要／分からない」で分けて、それぞれ理由を一言書いてください。
決めるのは私なので、「分からない」は無理に埋めなくて大丈夫です。

〔要点を貼る〕
```

AIが「たぶん不要」と言っても、決めるのは自分です。
「不要」にしたものが、実は返事を待たれていた、は普通にありえるので。

## 08｜AIに任せないこと

### 期日と「誰が何を頼んでいるか」は、原文で確かめる

研究で分かっていること（メールの研究ではありません）

- AIに診察の会話記録から診療メモを作らせた研究では、元の会話記録の文のうち3.45%で、その情報がメモから抜け落ちていました（Asgari ほか, 2025。約5万文を医師が確認。診療記録の要約で、1つのモデルの結果）
- メールから依頼や期日を抜き出すAIの正確さを測った研究は、見つかりませんでした

3.45%を「AIの取りこぼし率」として一般化はできません。モデルも課題も違うので。
ただ、「抜けることはある」という前提は持っておいたほうがよさそうです。

なので、AIの一覧は「拾い直しのきっかけ」にして、期日と依頼の中身は、元のメール・Slackで確かめます。
自分でまとめた要点の時点で抜けていることもあるので、そこも同じです。

### AIに渡さない連絡の種類

要点を貼るのもやめておいたほうがいい、とこの記事で考えているものです（研究の結論ではありません）。

- 評価・人事に関わる連絡（内容がそのまま個人の情報なので）
- 体調・配慮に関わる連絡（同じく、個人の情報で、言い回しも自分で決めたいので）
- 謝罪が必要な連絡（何を謝るかの判断は、自分にしかできないので）
- 社外との約束（金額・納期・契約）に関わる連絡（数字や条件の取り違えの影響が大きいので）
- 誰かの個人的な相談（相手が自分にだけ話している内容なので）

これらは、一覧に「〔相手A〕：要確認」くらいの1行だけ残して、中身は自分で見ます。

## 09｜分岐：こういうときは

1. 量が多くて追いつかないとき
→ 「返さなくてよい」の箱を先に広げます。CC・通知・共有だけのものは、まとめて「返さなくてよい」に。それでも多ければ、05の「優先が分からないとき」の一言で、上司にどれを先にするかを確かめる。全部を自分で並べなくて大丈夫です。

2. 量は少ないのに、忘れるとき
→ 仕組みを増やさずに、「一言で受け取る」と「期日を書いておく」の2つだけに絞ります。06の見直しは、「受け取っただけ」が1件以上ある日だけでもいいかもしれません。

3. 判断が要るものが溜まるとき
→ 中身を考える前に、「誰に確かめるか」と「いつまでに返すか」だけを一言で返します（05の「判断に時間がかかるとき」）。頭の中を外に出すこと自体が苦手な場合は、また別の話になりそうです。

4. 催促されてから気づいたとき
→ 謝りすぎずに、遅れたことを一言、いつ返すかを一言。

```
ご連絡ありがとうございます。お返事が遅くなってすみません。
〔◯日〕までにお送りします。
```

長い謝罪より、次の日付があるほうが、相手も動きやすいと思います。
そのうえで、その連絡がなぜ溜まったか（04の3つの箱のどれだったか）を、10のシートに1行メモしておくと、次の仕組みの手がかりになります。

5. 返信のことを考えるだけで、受信箱を開けないくらいしんどいとき
→ 仕組みより先に、休むことや、主治医や医療機関、職場の相談先への相談も選択肢に入れてください。

## 11｜分かっていないこと・この記事の提案（整理）

研究で分かっていること

- 大人のADHDでは、予定した行動をあとで実行することのつまずきが、小さな研究で報告されている。どの段階でつまずくかは研究によって違う
- 急ぎでない仕事のメールでは、受け手が「早く返さなきゃ」を送り手の期待より強く見積もりやすい。送り手の「急ぎではない」の一言で、ズレは小さくなった
- 「すぐ返さなきゃ」の気持ちが強い人ほど、疲れや睡眠の質の悪さと弱く関連していた（1回の調査）
- 1つの実験で、メールを見るのを1日3回にした週は、1日のストレスが少し低めだった（差は小さい。生産性の実感は差なし）
- AIの要約では、元の文書にある情報が抜けることがある（メールの研究ではない）

分かっていないこと

- ADHDの大人の、メール・チャットの返信の遅れや忘れ
- 未返信が溜まることと、ワーキングメモリや処理速度との関係
- 受け手が「受け取りました、◯日までに返します」と返すことの効果
- Slackなどのチャットで、返信の速さの期待のズレが同じように起きるか
- 1日の終わりに1回見直すことの効果
- 日本の職場で同じ結果になるか
- メールから期日を抜き出すAIの正確さ

この記事の提案（研究の結論ではない）

- 「返す」を、仕分ける・一言で受け取る・あとで中身を返す、の3つに分ける
- 受け取りの一言で、相手の待ちと自分の「あとで」を、両方〔◯日〕に変える
- 1日の終わりに「受け取っただけ」を拾い、期日を原文で確かめ、翌朝の1件を決める
- AIには一覧づくりと抜き出しだけを頼み、判断と送信は自分でする
