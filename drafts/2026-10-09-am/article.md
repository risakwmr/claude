## 01｜連絡そのものが、けっこう重い

休むこと自体より、「休みます」と送ることのほうが重い朝があります。

迷うポイントは、だいたいこのあたりだと思います。

- 理由をどこまで書くか（「体調不良」で足りる？ 病名や通院のことは？）
- いつ、誰に、どこで送るか（Slack？ メール？ チャンネル？ DM？）
- 今日の仕事をどうするか（会議、締切、返信待ち）
- 「また休むの？」と思われないか

全部を一度に考えようとすると、それだけで朝のエネルギーが終わります。
調子が悪い朝に、です。

私は、前の会社で「毎日出社できないなら休職になる」と言われたことがきっかけで、会社を辞めました。
上司や人事に、リモートワークなどの配慮を伝え続けてきたことも、これまでのnoteで書いています。

## 02｜研究で分かっていること：「休まない」は個人の性格だけの話ではない

研究の世界では、体調が悪いのに出勤・稼働することを「プレゼンティーイズム（sickness presenteeism）」と呼びます。

まず、その後の健康との関係です。
Skagen と Collins による2016年のシステマティックレビュー（Social Science & Medicine）は、453本の論文から基準を満たした縦断研究12本を集めて整理しています。

大半の研究で、ある時点で体調が悪いのに働いていたことは、その後の欠勤や、自分で評価した健康状態の悪さの「危険因子」になっていました。

ただ、ここは注意が必要です。

- 「危険因子」は時間的な前後関係のある関連で、「無理して働いたから悪くなった」という因果を示したものではありません
- 研究ごとにプレゼンティーイズムの定義や測り方がかなり違い、数字をまとめて統合することはできていません
- 心や体の健康への影響は、研究によって結果が一致していません

なので、「無理して出ると悪化する」とも、「何日休めば大丈夫」とも言えません。
集団で見た傾向の話で、一人ひとりに当てはまるかは分かりません。

次に、なぜ体調が悪くても働くのか。
Miraglia と Johns による2016年のメタ分析（109サンプル、合計175,965人）では、体調が悪いのに出勤することと関連する要因として、次のようなものが挙がっていました。

- 身体の健康状態の悪さ
- 厳しい欠勤のルール
- 雇用の不安定さ
- 仕事の要求の高さやストレス
- サポートの少なさなどの「資源」の少なさ

ほかに、仕事への満足やコミットメントの高さなど、前向きな態度とも関連していました。
（これも関連で、原因かどうかまでは言えません）

もう一つ、休まない理由には「自分で選んで出る」ものと「圧力を感じて出る」ものがある、と整理した研究もあります（Van Waeyenberg, 2024）。
所属機関のページに載っている抄録で確認できた範囲では、4つの研究（計1,021人）で、圧力を感じて出るほうは、時間がたつとバーンアウトの高さと関連していたそうです。
（論文の本文までは確認できていないので、ここはこのくらいの紹介にとどめます）

ここから私が受け取ったのは、
「休みの連絡をためらうのは、気が弱いからとは限らない」
ということです。
ルールや雇用の状況、職場のサポートなど、環境の側の話でもある。

じゃあ、連絡文をどう書けば上司に受け止めてもらいやすいのか。
……ここは、調べた範囲では研究が見つかりませんでした。
連絡の文面そのものを扱った査読研究は、今回の検索では出てこなかったです（出てくるのはテンプレート紹介の記事ばかり）。

なので、ここから先の文面は研究の結論ではなく、この記事の提案です。

## 03｜無料で持ち帰れる軸：当日連絡の4つの要素

この記事の提案として、当日の連絡を4つの要素に分けてみます。

1. 今日の状態：「体調が優れないため」くらいの一言
2. 稼働の見込み：休む／何時から始める／在宅で軽めに動く
3. 急ぎの対応：今日の会議や締切を、誰に・どうお願いするか
4. 次の連絡：いつ、また連絡するか

ポイントは、理由（病名や通院のことなど）は必須の要素に入れていないことです。
上司やチームが当日いちばん困るのは、たぶん「今日、何が止まるのか」が分からないことで、理由はそのあとでもいい、という考え方です。
（理由をどこまで伝えるかは、前に「職場に、心の調子をどこまで伝える？」で「誰に・何を・いつ」に分けて書きました）

4つだけ入れた、いちばん短い形はこんな感じです。

```
おはようございます。体調が優れないため、本日はお休みします。
10時の定例は欠席します（資料は共有フォルダにあります）。
明日の朝9時までに、明日の予定をあらためてご連絡します。
```

「次の連絡」を入れておくと、自分の側も「今日はもう連絡を考えなくていい」状態に近づけます。
休む日に、何度もSlackを見なくて済む（かもしれない）。

ひとつだけ、聞かせてください。

当日の連絡でいちばん迷うのは、①理由をどこまで書くか ②何時に・誰に送るか ③今日の仕事をどうするか のどれですか？ コメントで番号だけでも教えてもらえたら嬉しいです。

このシリーズ「心の調子と働く」は、マガジンにまとめています。
続きを読みたい方は、フォローしてもらえると励みになります。

## 05｜状況別の連絡文（日本語）

以下はこの記事の提案です。研究で効果が確かめられた文面ではありません。
社内の言い方（「お休み」「有休」「欠勤」など）や、届け出の方法は会社の規程に合わせてください。

〔 〕の中は自分の状況に置きかえてください。

### A｜全休するとき

Slack（理由を書かない）

03の最短の形に、予定のリスケと、代わりの人へのお願いを足した形です。

```
おはようございます。体調が優れないため、本日はお休みします。
〔14時の〇〇さんとの打ち合わせ〕は、〔明日以降〕にリスケさせてください。〔〇〇の確認〕は〔△△さん〕にお願いできますか。
今日は返信できません。〔明日の朝9時〕までに、明日の予定をご連絡します。
```

Slack（理由を少し書く）

```
おはようございます。〔通院の関係で／持病の関係で〕体調が優れず、本日はお休みします。
〔今日締切の〇〇〕は、〔明日の午前中〕に提出させてください。
〔明日の朝9時〕までに、あらためてご連絡します。
```

※「持病」「通院」と書くかどうかは、開示の判断です。書かなくても連絡としては成り立ちます。

メール（上司が別チーム・社外の予定がある場合など）

```
件名：本日のお休みについて（〔名前〕）

〔上司名〕さん

おはようございます。〔名前〕です。
体調が優れないため、本日はお休みをいただきます。

本日の予定への影響は次のとおりです。
・〔10時 〇〇定例〕：欠席します。資料は〔場所〕にあります
・〔〇〇の締切〕：〔明日の午前中〕に提出させてください

急ぎの件は〔〇〇さん〕にお願いしています。
〔明日の朝9時〕までに、あらためてご連絡します。
```

### B｜遅れて始める・半休にするとき

```
おはようございます。体調が優れないため、本日は〔12時〕から稼働します。
〔10時の定例〕は欠席します。〔議事メモを後で確認します〕。
〔11時半〕の時点でまだ難しければ、そこで全休に切り替えてご連絡します。
```

「〇時から」と書くときは、無理だったときの次の一手（全休に切り替えるかどうかを、何時に連絡するか）もセットにしておくのが、この記事の提案です。
「午後から行けます」と書いて行けなかったときの、二通目を考える重さが少し減ります。

### C｜在宅・低稼働に切り替えるとき

```
おはようございます。体調が万全ではないため、本日は在宅で、軽めに稼働します。
会議は〔〇〇定例〕のみ出て、ほかは失礼します。
返信は遅くなるかもしれません。急ぎの件はメンションをお願いします。
```

※在宅への切り替えができるかどうかは、会社や職種のルール次第です。
※調子が落ちている日の仕事の組み立て方は「100%で働けない日の仕事術」で書いたので、ここでは連絡だけにします。

### 迷ったときの分岐（この記事の提案）

- 「何時から動けるか分からない」とき → Aの全休で送って、動けそうなら後で「午後から少しだけ見ます」と足す。逆（Bで送って、あとから全休）より、二通目が軽く済むことが多いと思います（推測です）
- 今日どうしても外せない予定があるとき → その予定だけを「急ぎの対応」に書き、誰に何をお願いしたいかを具体的に書く
- 上司がチャンネルでの連絡を求めているか、DMを求めているか分からないとき → 元気な日に一度聞いておく（08のチェックリストへ）

## 06｜英語版の連絡文（外資の上司・チーム向け）

これもこの記事の提案です。sick day、PTO、sick leave などの呼び方や使い分けは会社によって違うので、社内でよく使われている言い方に合わせてください。

### A｜全休

```
Hi 〔name〕, I'm not feeling well this morning, so I'm taking a sick day today.
I'll skip 〔the 10am sync〕. 〔The deck is in the shared folder.〕
I'll update you by 〔9am tomorrow〕 on my plan for tomorrow.
```

理由を少し書くなら：

```
Hi 〔name〕, I'm dealing with a health issue this morning and need to take today off.
Could 〔teammate〕 cover 〔the 10am sync〕? I'll share an update by 〔9am tomorrow〕.
```

※ "a health issue" で伝わることが多いと思います。病名を書く必要はありません（書くかどうかは開示の判断です）。

### B｜遅れて開始

```
Hi 〔name〕, I'm not feeling great this morning. I plan to start around 〔noon〕.
I'll miss 〔the 10am sync〕 and catch up on the notes afterward.
If I can't make it by 〔11:30〕, I'll let you know and take the full day off.
```

### C｜在宅・低稼働

```
Hi 〔name〕, I'm not at 100% today, so I'll work from home and keep it light.
I'll join 〔the team sync〕 only. Replies may be slower than usual. Please @ me if anything is urgent.
```

（もっと自然な言い回しがあると思います。社内でみんなが使っている表現があれば、それに寄せるのがいちばんです）

## 07｜連絡が続くとき

1回目より、2回目・3回目の連絡のほうが重い、という人は多いと思います。
ここは研究が見つからなかった部分なので、全部この記事の提案です。

### 2回目・3回目の文面

続くときは、「今日の連絡」に加えて「続いていることに自分も気づいている」と一言入れる形を提案します。
相手に先に言われる前に、こちらから言っておく、くらいの意味です。

```
おはようございます。今週2回目で申し訳ないのですが、体調が優れないため本日もお休みします。
〔今日の予定への影響〕。
続いているので、来週どこかで15分ほど、今後の進め方を相談させてもらえますか。
```

```
Hi 〔name〕, sorry, this is my second sick day this week. I'm not feeling well again and will take today off.
Since this has come up a few times, could we find 15 minutes next week to talk about how I can plan my work?
```

※「申し訳ない」「sorry」を入れるかどうかは好みです。入れすぎると、毎回謝る形になって自分がしんどくなるかもしれません。

### 1on1で相談に切り替える目安

次の数字は目安で、研究が示したものではありません。会社の規程や主治医の意見があれば、そちらが優先です。

- 同じ週に2回以上（目安）、当日の連絡をした
- 同じ月に3回以上（目安）、当日に予定を変えた
- 「次の連絡」で約束した時間に、連絡を入れるのが難しくなってきた

どれかに当てはまったら、当日の連絡とは別に、元気なタイミングで相談の時間をもらう。
当日の朝に、仕事の進め方まで話そうとしなくて大丈夫です。

### 相談で話す3点（この記事の提案）

1. 何が起きているか：当日の連絡が続いていること（理由をどこまで話すかは自分で決める）
2. 今の仕事への影響：止まっているもの、遅れそうなもの
3. 相談したいこと：締切の置き方、会議の出方、連絡のルール（「当日はSlackの一言でいい」など）

※休職や、働き方そのものを大きく変えるかどうかの判断は、この記事では扱いません。主治医・産業医・人事などに相談してください。

## 08｜元気な日に決めておくチェックリスト

調子が悪い朝に、ゼロから考えないための準備です。これもこの記事の提案です。

```
【元気な日に決めておくこと】
□ 当日の連絡は誰に送るか（上司／チームのチャンネル／両方）
□ Slackかメールか。何時までに送るか
□ 上司が「理由」をどこまで求めているか、一度聞いておく
□ 05・06の文面を、自分用に直して保存した（メモアプリなど、朝すぐ開ける場所）
□ 自分がいないと止まる仕事と、代わりに頼める人のメモ
□ 定例の資料やメモの置き場所が、チームに分かる状態になっている
□ 会社の規程（届け出の方法・期限）を一度読んだ
```

### AIに連絡文の下書きを頼むとき

私は英語のメールやSlackの返信にAIを使っていますし、AIに頼むときは「私に質問して」と頼むことが多いです。
自分が分かっているつもりのことも、「なんで？」と聞かれると意外に答えられないので。

連絡文でも、いきなり「書いて」より、先に聞いてもらう形が使えると思います。

```
今日、体調が悪くて仕事を休む（または遅れて始める）連絡を上司に送ります。
文面を書く前に、「今日の状態・稼働の見込み・急ぎの対応・次の連絡」の4つについて、私に1つずつ質問してください。
理由（病名など）は聞かなくて大丈夫です。
最後に、Slack用の3行以内の文面を日本語と英語で作ってください。
```

※病名や通院先など、個人の健康情報をどこまでAIに入れるかは、会社のルールと自分の線引きで決めてください。
※調子が悪い朝は、AIとやり取りする余力もないかもしれません。なので、この頼み方は元気な日に使って、文面を保存しておく使い方のほうが合っている気がしています。

## 10｜研究で分かっていること／分かっていないこと

分かっていること

- 体調が悪いのに働くことは、多くの縦断研究で、その後の欠勤や自己評価の健康の悪さの危険因子になっていた。ただし因果ではなく、研究間で定義や測り方がばらばらで、健康への影響の結果も一致していない（Skagen & Collins, 2016）
- 体調が悪いのに出勤することは、厳しい欠勤ルール、雇用の不安定さ、仕事の要求の高さ、サポートの少なさなどと関連していた（Miraglia & Johns, 2016。関連の強さの数値は確認できていないので書いていません）
- 休まない理由には「自分で選ぶもの」と「圧力によるもの」があり、圧力によるものはバーンアウトの高さと関連していた、と報告する研究がある（Van Waeyenberg, 2024。抄録の範囲で確認）

分かっていないこと（今回確認できなかったものを含む）

- 欠勤・遅刻の連絡の書き方（理由の有無、時刻の入れ方）と、上司の受け止めやその後の評価との関係。調べた範囲では研究が見つかりませんでした
- うつなど心の不調に絞ったプレゼンティーイズムのレビューで、身体の不調と比べたもの。コロナ禍の労働者のメンタルヘルスとプレゼンティーイズムをまとめたレビュー（García-Iglesias ほか, 2023）はありますが、ほとんどが一時点の自己申告の調査で、原因か結果かは分かりません
- 当日の半休や在宅への切り替えが、全休よりいいかどうか。北欧には「部分的な病休」と全日の病休を比べた研究の整理がありますが（ノルウェー公衆衛生研究所, 2018）、ほとんどが観察研究で、著者も確かな結論は出せないとしており、医師の診断書のある病休制度の話なので、日本の会社の半休・在宅とは別物です
