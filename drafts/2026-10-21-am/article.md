## 01｜思い出せないのは、努力不足というより記憶の性質に近い

まず、記憶の研究から。

自分に起きた出来事の記憶（自伝的記憶）については、日々の出来事を日記に残しておいて、あとでどれくらい思い出せるかを試す研究が昔からあります。
結果の方向は、だいたいそろっています。

- 時間がたつほど、思い出せるのは一部になる。正確な日付まで言えることは少なかった（Storms, 2024。研究者本人1人の、24年分の日記を使った研究です）
- 数週間の範囲でも、まず抜けていくのは出来事の細かいところだった（Kristo ほか, 2009。878人のウェブ日記の研究）
- 時間がたって正確さが下がっても、本人の自信は高いままだった（Barclay & Wellman, 1986）
- よく思い出せたのは、何度も思い返したり、人に話したりした出来事だった（Storms, 2024／Kristo ほか, 2009）

最後の1つを裏返すと、誰にも話さない毎週の地味な仕事は、思い出しにくい側に入りやすいのかもしれません。
（これは推測です。仕事の出来事そのものを対象にした日記研究は、今回は見つかりませんでした）

どれも「その人の記憶力が悪い」という話ではありません。
半年分を思い出せないのは、努力不足というより、記憶の一般的な性質に近い。
研究から言えるのは、このくらいまでです。

「半年で◯%忘れる」のような数字は、研究によって期間も出来事も測り方も違うので、ここでは出しません。

## 02｜評価する側の「日誌」の研究はある。本人の記録の研究は、今回の調べでは見つからない

評価そのものも、「観察する → 覚える → 思い出す → まとめて判断する」という記憶の流れとして研究されてきました（DeNisi, 1996）。

その中に、評価する側（上司）に日誌をつけてもらった現場の研究があります。
2つの組織で、評価者に決まった形の日誌をつけてもらい、決まった手順で思い出してもらいました。
すると評価者は部下の仕事ぶりをよりよく思い出せて、評価が甘くなりすぎず、差がはっきりした評価になりました（DeNisi & Peters, 1996）。

ただ、同じ研究グループの別の現場研究（評価者85人・評価される人404人）では、日誌をつけた条件で、上司の「好き嫌い」と評価の関係がむしろ強くなっていました（Varma ほか, 1996）。
なので、「日誌をつければ公平になる」とは単純には言えません。

そして、ここが一番大事なところです。
どちらも、評価する側が記録をつけた研究です。
評価される本人が自分で記録をつけたとき、自己評価や上司の評価がどう変わるかを直接調べた研究は、今回の調べでは見つかりませんでした。

もう1つ。
「評価は最近のことに引っ張られる」はよく聞きますが、研究は少なく、実験室のものが中心です。低い成績の場面が評価期間の最初にあったときのほうが評価が低くなった、という結果もあります（Rosales ほか, 2021。スペインの大学生146人の実験）。
「最近のことしか評価されない」とまでは言えないんですよね。

## 03｜振り返りを書く研究も、ある。でも条件つき

振り返りを書くことについては、よく紹介される実験があります（Di Stefano ほか, 2014。2023年に改訂版）。

インドのBPO企業1社のコールセンターで、研修を受けている新人が対象です。
研修の6日目〜16日目、毎日の最後の15分で「その日学んだこと」を書いて振り返りました。
その人たちは最後の研修テストで、その15分も作業を続けた人たちより22.8%成績がよかった、と著者の所属機関が紹介しています。

ただ、条件を並べると、

- 査読前の研究（ワーキングペーパー）
- 測ったのは研修テストの成績で、仕事の成果や人事評価ではない
- 毎日15分・研修期間の話で、この記事の「週1回」とは条件が違う

なので、言えるのは「新しい仕事を覚える時期に、学んだことを書いて整理すると、同じ時間を作業に使うより学習テストの成績がよかった、という査読前の実験がある」まで。
「記録すると評価が上がる」とは、この研究からは言えません。

## 06｜無料で持ち帰れる型：3行だけ、週1回

ここからは研究の結論ではなく、この記事の提案です。
「週1回」「3行」は目安で、研究が示した区切りではありません。

残すのは、この3行だけ。

```
やったこと：
誰に効いたか：
証拠の場所：
```

- やったこと：自分がしたことを1行。良かったかどうかの判断は、ここでは書かない
- 誰に効いたか：名前ではなく役割で（「依頼してくれた人」「隣のチーム」「新しく入った人」）
- 証拠の場所：資料・スレッド・ダッシュボードの「場所」だけ。中身は貼らない

たとえば（架空の例です）、

```
やったこと：新しく入った人向けに、作業の手順を1枚にまとめた
誰に効いたか：隣のチームの新しく入った人（質問が減ったと言われた）
証拠の場所：チームの共有フォルダの手順書
```

これだけです。

最初の一歩は、週に1回、曜日を決めて、1件だけ。
書けない週は飛ばして大丈夫です。

01の研究を思い出すと、細かいところから先に抜けていく。
なので、細部まで全部書くより、「あとで探しに行ける手がかり」を残すくらいでいいのかもしれません。

※「仕事が終わっても頭から離れない人へ」【🔗リンクを貼る（任意）】で書いた終業前の手順とは、目的が別です。あちらは頭から仕事を下ろすため、こちらはあとで説明するための記録です。

ひとつだけ、聞かせてください。

評価の前、思い出すのにいちばん使うのは、①カレンダー ②Slack・メール ③自分のメモ ④その場で思い出す のどれですか？ コメントで番号だけでも教えてもらえたら嬉しいです。

「AIに渡す仕事、渡さない仕事」は、マガジンにまとめています。
続きを読みたい方は、フォローしてもらえると励みになります。

## 07｜コピー用：週1回の成果メモのひな形

最初にお断りです。
07〜11は、すべてこの記事の提案です。頻度や区切りは目安で、研究が示したものではありません。

```
【成果メモ】〔◯月 第◯週〕
やったこと：〔自分がしたことを1行。判断や形容詞は入れない〕
誰に効いたか：〔役割で：依頼してくれた人／隣のチーム／新しく入った人 など〕
証拠の場所：〔資料・スレッド・ダッシュボードの場所。中身は貼らない〕
（任意）次にやること：〔1行〕
```

書くときのコツ。

- 「やったこと」は事実だけ。「うまくいった」「大きく改善した」は、束ねるとき（11）に考える
- 「誰に効いたか」に人の名前を書かない。メモの中に、ほかの人の情報を増やさないためです
- 「証拠の場所」は、あとで自分が探しに行ける程度で十分
- メモ自体は、会社のルールで認められた場所に置く

名前や固有名詞の置き換え（例）。

- プロジェクト名 → 〔プロジェクトA〕
- 取引先・社外の名前 → 〔取引先1〕
- 数字 → AIに頼む内容に要らなければ消す

ただ、伏せればAIに入れてよい、という話ではありません（国のガイドラインや個人情報保護委員会の注意喚起にも、そうは書かれていません）。
名前を伏せても、時期や数字の組み合わせで分かってしまうことがあります。
迷ったら、AIに渡す仕事 #06 の聞き方で確かめてください【🔗リンクを貼る／未公開なら「迷ったら、上司か、社内でAIのルールを決めている部署に、使ってよい情報の範囲を確かめてください。」に置き換え】。

## 08｜コピー用：AIへの頼み方4つ

この文面で内容が足されにくくなるかは、確かめられていません。
どれも、AIに渡すのは自分が書いて置き換えたメモだけ。「証拠の場所」の行は外して渡します。

頼み方1：3行を読みやすく整える

```
以下は、私が書いた今週の仕事のメモです（名前や固有名詞は置き換えてあります）。
読みやすい文に整えてください。
・メモに書いていない事実・数字・成果は足さないでください
・「大きく」「大幅に」など、強める言葉を足さないでください
・意味が分からないところは、推測で埋めずに質問してください
・最後に、元のメモから変えたところを箇条書きで示してください

〔メモ〕
```

頼み方2：足りないところを質問してもらう

```
以下のメモを読んで、「やったこと」「誰に効いたか」で、あとで説明するときに足りなくなりそうなところを、私に質問してください。
質問は2つまで。答えは私が書くので、あなたは書き足さないでください。

〔メモ〕
```

（AIに質問してもらう頼み方は、AIに渡す仕事 #04 に詳しく書いています【🔗リンクを貼る／未公開なら、この1文を削除】）

頼み方3：4週分を「何が変わったか」でまとめる

```
以下は4週分の仕事のメモです。
「何が変わったか」の観点で、3行にまとめてください。
メモにないことは足さず、どの週のメモから取ったかを（第◯週）で添えてください。

〔4週分のメモ〕
```

頼み方4：評価の前に、4つの観点で並べ替える

```
以下は〔期間〕の仕事のメモです。
1件ずつ、「何が課題だったか／自分は何をしたか／誰と関わったか／結果として何が変わったか」の4つに並べ替えてください。
メモに書かれていない項目は、空欄のまま「メモにない」と書いてください。

〔メモ〕
```

4つの観点は、外資テック解剖 #02 で書いた、成果を残すときの観点です。
3行メモは毎週残すためのもの、4つの観点は評価の前に束ねるときのもの、と役割を分けています。

AIに渡さないこと

- どの成果が大事か、という重みづけ
- 自己評価に書く言い回しの最終決定
- 会社の資料・メール・Slackのやり取りそのもの（会社が用意したAIを使う場合も、ルールで認められた範囲だけ）
- ほかの人の名前や、その人への評価

【✏️要記入：メモや自己評価の文を、AIに整えてもらうことがあるか。あれば、どこまで頼んでいるか。（ガイド：「整えるだけ」「質問してもらうだけ」「使っていない」など一言で。AIの名前・社内ツールの名前、会社のルールで何が許されているかは書かない）】

## 09｜AIが整えた文を、元のメモと見比べる

### 研究で分かっていること

- AIの「ハルシネーション（もっともらしいが事実でない内容）」には、世の中の事実と違うものとは別に、渡した入力や指示からずれるものがある、と整理されています（Huang ほか, 2025）。メモにないことが入るのは、こちらの種類です
- 科学論文の要約をAIに頼んだ研究では、「正確に」と指示しても、多くのモデルが原文より広く・強く言い切る要約を作っていました（Peters & Chin-Yee, 2025）
- 履歴書を求人に合わせて書き直させた実験では、「根拠のない事実を足さない」と指示しても、根拠のない記述はなくなりませんでした（Takano, 2026。査読前）

本人が書いた数行のメモを整えさせたとき、どれくらい足されるかを直接調べた査読済みの研究は、見つかっていません。
なので割合は出しません。言えるのは「足されることがある。頼み方で減ることはあっても、なくなるとは限らない」まで。

### 見比べるチェックリスト

```
□ 元のメモと、AIが整えた文を横に並べた
□ 整えた文の1文ずつ、元のメモのどこから来たか指させる
□ 元のメモにない数字・人・成果が入っていない
□ 「少し」「一部」などの控えめな言い方が、強い言い方に変わっていない
□ 「〜した」が「〜を主導した」「〜を実現した」のように大きくなっていない
□ 元のメモにあったことが、抜けていない
→ 指させない文は、消すか、元のメモの言い方に戻す
```

残しておくのは、元のメモのほうです。
AIが整えた文は、読みやすくした「表示用」くらいに思っておく。
（自分の成果だと、盛られても気づきにくいのがちょっと怖いところです、、、）【🟡確認：このかっこ書きはSenaの感じ方として読まれます。合わなければ削除してください】

## 10｜分岐：自分の状況に合わせる

- 毎週書ける → 3行を週1回。4週たまったら頼み方3でまとめる
- 毎週は無理、月1回が限界 → 月に1回、カレンダーを1か月分だけ見て、1件だけ書く。01のとおり、あとになるほど細部が抜けやすいので、「証拠の場所」だけは必ず残す
- 数字が出にくい仕事 → 「誰に効いたか」を少し厚めに。証拠の場所に「お礼のメッセージがあったスレッド」「依頼されたときのメール」など
- チームの成果が大きい → 「やったこと」は、チーム全体ではなく自分の担当部分だけ。「チームで〜」と書いたら、「そのうち自分は〜」を1行足す
- 調子が低い週 → 「やったこと」1行だけでいい。「誰に効いたか」「証拠の場所」は空欄でOK。それも無理なら、日付だけ書いて閉じる

調子が低い週の分、あとで取り戻そうとしなくて大丈夫です。

【✏️要記入：調子が低い時期に、仕事の記録をどうしているか（していたか）。（ガイド：「低い週は書かない」「1行だけ書く」「特に変えていない」など一言で。体調や治療の具体は書かなくて大丈夫です）】

## 11｜評価の前に、メモを束ねる手順

評価の直前の動き方は外資テック解剖 #05 にあるので【🔗リンクを貼る／未公開なら、この部分を「評価の直前の動き方には触れず、」に置き換え】、ここでは「たまったメモをどう渡すか」だけ書きます。

1. 期間中のメモを、1か所に集める（元のメモのまま）
2. 「証拠の場所」の行を外したうえで、頼み方4で4つの観点に並べ替えてもらう
3. 「メモにない」と出た項目を、自分で埋めるか、その件ごと外す

## 13｜研究で分かっていること／分かっていないこと

### 研究で分かっていること

- 自分の出来事の記憶は、時間とともに一部しか思い出せなくなり、細部から抜けやすい。本人の自信は下がりにくい（01。どれも仕事ではなく日常の出来事の研究）
- 評価する側（上司）が日誌と決まった思い出し方を組み合わせると、部下の仕事ぶりをよりよく思い出せた。ただし、日誌で偏りが消えるとは言えない（02）
- インドの1社の新人研修で、毎日の最後の15分に学んだことを書いて振り返った人は、同じ時間を作業に使った人より研修テストの成績がよかった、という査読前の実験がある。仕事の成果や評価は測っていない（03）
- 要約や記録づくりをAIにさせた研究で、入力にない内容が足されたり、言い方が強くなったりすることが報告されている（09）

### 分かっていないこと

- 評価される本人が自分の仕事を記録すると、自己評価や上司の評価がどう変わるか
- 実際の職場の評価期間で、「最近の出来事」への偏りがどれくらい起きるか
- 仕事の出来事を、評価期間のあいだにどれくらい思い出せなくなるか
- 数行のメモをAIに整えさせたとき、内容が足される割合
- 週1回・3行のような頻度や項目数の効果（06〜11はこの記事の提案です）

## おわりに

半年分を思い出せないのは、たぶん、あなただけじゃない。
