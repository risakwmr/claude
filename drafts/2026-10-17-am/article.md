## 01｜調子が低い朝は、「始める」までが重い

調子が低い日は、頭が止まる、というより、重くなる感じに近いです。

私の場合、最初のサインは「めんどくさい」です。
いつもならサクサク進める返信が、できなくなる。
長い文章も、頭に入ってきません。
（そもそもベッドから動けない日も、よくあります）

私はうつで、大学時代に発症して今も治療中です。
「100%で働けない日の仕事術」でも書いたように、大きな判断や新しいことを始めるのは、しません。というかできません。

ただ、その日の「全部やらない」を決めたあとにも、最初の一歩の重さは残ります。
今日はその部分だけを見てみます。

## 02｜研究で分かっていること・分かっていないこと

### 分かっていること

まず研究から。

Rock らの系統的レビューとメタ分析（2014、Psychological Medicine）は、うつのある人と、ない人を、同じ認知検査（CANTAB）で比べた研究をまとめています。
結果は、実行機能（計画する、切り替える、など）・記憶・注意に、中くらいの差があるというものでした（効果量 d は −0.34〜−0.65）。
さらに、症状が落ち着いた（寛解した）人でも、実行機能と注意には中くらいの差が残る傾向がありました。

つまり「調子が低い日に、考えて・始めるのが重い」のは、気合いの問題というより、うつという状態に伴うことがある、と研究は言っています。

もうひとつ。
Ekers らのメタ分析（2014、PLoS ONE）は、「行動活性化」という方法（やる気が出るのを待たず、小さな活動から始める）の無作為化試験26本、計1524人をまとめました。
治療後のうつ症状は、何もしない比較群より低く（SMD −0.74）、薬との比較（4試験）でもやや低い結果でした（−0.42）。

### 分かっていないこと・注意点

- Rock らのレビューは、特定の検査（CANTAB）で測った結果です。実際の仕事のしやすさ（メールを書く、資料を作る）が、この差で決まるとは言えません。
- 「差がある」は平均の話です。同じうつでも、人によって、日によって違います。私自身がこうだ、という話でもありません。
- Ekers らのメタ分析は、研究の質が低いものが多く、追跡期間も短いと著者自身が書いています。しかも、これは「行動活性化」という治療の研究で、AIに下ごしらえを手伝ってもらうことの効果を調べたものではありません。
- 「AIに手伝ってもらうと、立ち上がりが楽になる」ことを直接確かめた研究は、今回の調査では確認できませんでした。以降のやり方は、研究の結論ではなく、私（Claude）の提案です。

## 03｜無料で持ち帰れる軸：「下ごしらえ」と「決める」を分ける

提案です。
立ち上がりの重さは、実は2種類の作業が混ざっている気がします。

下ごしらえ：何があるか書き出す、並べる、下書きを作る、候補を出す
決める：どれからやるか、これで送るか、今日はやらないか

研究が言っていたのは、計画したり切り替えたりする力が重くなりやすい、ということでした。
だとすると、「下ごしらえ」はAIに渡して、「決める」は自分の手元に残す、という分け方は筋が通りそうです。
（研究がそう言っているわけではなくて、つなげて考えるとそうなるかも、という私の提案です）

「決める」を残す理由は、もうひとつあります。
AIが出した最初の一歩を、ただ受け取ると、「AIが決めたから」になってしまうからです。
なので、AIに聞く前に、一度だけ自分で考えてから渡したいと思っています。
「私はこう思ったんだけど、どう思う？」は、よく書く頼み方です。

無料で持ち帰れる一歩は、これだけです。
AIに頼む前に、1行だけ書く。

「今日、終わらせなくていいのはどれ？」

下ごしらえを頼む前に、これを自分で決めておくだけで、AIに出してもらうリストの長さが変わります。

## 04｜私の場合

【🟡確認（Senaに質問中・Q1）：10/15に、AIエージェントにメールを読み取ってもらい、議事録を作り、次の行動をまとめて実行まで任せている、と伺いました。公開記事では確認できていないので、調子が低い朝にも同じように使っているのか、書いてよいのかを決めてください。ツール名（Antigravity）は勤務先の推測につながるかもしれないので、「AIエージェント」のままが安全です】

調子が悪い日に、私がAIに頼んでいるのは、だいたいこの3つです。

・チャットやメールを元に、見逃しているタスクを洗い出してもらう
・長い文章や資料を、インフォグラフィックにしてもらう
・返信の下書きを作ってもらう（内容を確認して、送るのは自分）

逆に、1on1のように議論が必要な会議は、AIを介さず、自分で参加します。
送信ボタンを押すところも、任せません。
（このあたりは「100%で働けない日の仕事術」にも書きました）

調子が悪い日は、文章をまとめるだけでも、ものすごくエネルギーを使います。
なので、下書きやタスクの整理をAIに手伝ってもらえるのは、かなり助かっています。
私にとっては「甘え」というより、仕事を続けるための道具です。

変わらないのは、確認は結局自分、ということ。
しかも調子が悪い日は、その「確認する力」も落ちている日です。
AIが出したものをそのまま通してしまうリスクは、調子が悪い日ほど高くなる気がしています。

## 05｜AIへの頼み方5つ（コピー用）

どれも、最後の「決める」は自分に残す形にしています。
〔 〕は自分の内容に置きかえてください。社名・プロジェクト名・人の名前は入れないほうが安全です。

```
頼み方1：返信を並べる
以下は、今日返信が必要そうなメールとSlackの要点です（貼り付け）。
返信が急ぎのものから順に並べて、それぞれ「1文で返せるか／考える必要があるか」を教えて。
並べ替えるだけで、返信文は書かないで。
```

```
頼み方2：下書きだけ作る
次のメールへの返信の下書きを、短く2案作って。
私が言いたいことは「〔　〕」です。
送るかどうかと、言い回しの最終調整は私がやります。
```

```
頼み方3：最初の一歩を3候補出す
今日やる仕事は〔　〕です。
調子が低いので、5分で始められる最初の一歩を3つ候補で出して。
どれにするかは私が選びます。
```

```
頼み方4：今日やらないことを一緒に探す
今日やる予定の仕事は次のとおりです（貼り付け）。
私は今日、全部はできない前提です。
「今日やらなくても影響が小さそうなもの」の候補と、その理由を出して。
やらないと決めるのは私です。
```

```
頼み方5：私に質問して
今日の仕事が始められません。
状況を整理したいので、私に質問して。
質問は1回に1つ、全部で5つまで。
```

## 06｜分岐：今日の状態別

これは研究が示したものではなく、私の提案です。数字や区切りは目安です。

まだ動ける日：頼み方1と2。並べて、下書きを作ってもらい、確認は自分。
重い日：頼み方3と4。最初の一歩を決めて、今日やらないものを決める。
ほぼ動けない日：頼み方5だけ、または頼まない。AIを開くことも負担になる日は、無理に使わない。

「使わない」も選択肢です。AIを使えなかった日を、「また使えなかった」と数えないでください。

⸻

## 07｜AIに渡す前・渡したあとのチェックリスト

渡す前
- 今日終わらせなくていいものを、1つ自分で決めた
- 貼り付ける内容に、社外に出してはいけない情報が入っていない（会社のルールがあればそれに従う）
- 頼むのは「下ごしらえ」だけで、「決める」は自分に残してある

渡したあと
- 出てきたものを、そのまま送っていない
- 一歩目の候補から、自分で1つ選んだ
- 重いと感じたら、そこで止めてよいと決めている

調子が低い朝なら、頼み方5がいちばん近い形です。

## おわりに

調子が低い日に、全部を自分でやらなくてもいいと思っています。
ただ、AIに全部渡したら楽になる、とも言い切れない。
下ごしらえはAIに、決めるのは自分に、くらいが、今のところちょうどいいかもしれません。

立ち上がりが重い朝は、たぶんこれからもあると思います。
そのときに、最初の一歩を自分ひとりで探さなくていい、くらいの道具があると、少しだけ楽かもしれません。
