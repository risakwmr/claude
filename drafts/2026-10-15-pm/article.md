## 01｜診察で、仕事の話まで届かない

診察で仕事のことが言えない理由は、いくつかある気がします。

- 時間が短くて、体調の話だけで終わる
- 「仕事がしんどい」以上の言葉にならない
- 何が「先生に言うほどのこと」なのか、自分で判断できない
- その場で思い出せない。家に帰ってから出てくる

私は、大学時代にうつを発症して、今も治療を続けています。
これまでのnoteでも書いていますが、受診の前に、相談したいことをAIにまとめさせて、診察でそれを先生に読んでもらうことがあります。

理由の一つは、私が「頭の中を外に出す」のが苦手だからです。
知能検査の記事でも書きましたが、新しいことを理解したり、初見の問題を考えたりするのは得意な一方で、考えていることを言葉にして外に出すのは苦手なほう。
短い診察時間の中で、その場で整理して話すのは、なかなか難しいです。

もうひとつ、AIに頼むときは「私に質問して」と頼むことが多いです。
自分では分かっているつもりのことも、「なんで？」と聞かれると、意外に答えられないので。
受診の前の準備にも、この頼み方は使えそうだと思っています。

ただ、
「メモを作っていけば、診察がうまくいく」
と言えるのかというと、そこは研究を見ると、そんなに簡単ではなさそうでした。

## 02｜研究で分かっていること：準備すると、質問は少し増える。でも、それだけかもしれない

### 受診前の準備のまとめ（Cochrane、2007年）

診察の前に、患者が聞きたいことを準備できるようにする取り組みの効果をまとめた、Cochrane のシステマティックレビューがあります（Kinnersley ほか, 2007）。
6か国（主にアメリカ）の33のランダム化比較試験、合わせて8,244人分です。
取り組みの中身は、主に質問を書き出すシートと、コーチングでした。

結果は、

- 診察中にする質問の数は、少し増えた（効果は小さい）
- 満足度も、わずかに上がった
- 不安と、病気についての知識は、はっきりした変化なし
- 診察時間は、全体では延びていなかった（診察の直前に行った場合だけ、延びていた）

著者の結論は「患者への利益は限られている」です。
2007年のレビューで、調べた範囲では新しい版は見つからなかったので、やや古いものです。
対象には精神疾患も挙がっていますが、精神科の試験が何本あって、そこで効果が違ったかは、確認できていません。

### うつの外来での研究

精神科で近いものを探すと、うつ病の外来患者100人で、質問シートを配る効果を調べたランダム化比較試験が1本ありました（Hamann ほか, 2014）。
こちらは、患者が出した話題の数は増えませんでした。
著者は、すでに関係ができている医師と患者の間では、もっと複合的な取り組みが必要かもしれない、と書いています。

小さな研究1本で、しかも「シートを配る」もので、自分で自分の状況をメモにまとめていくのとは違います。
なので「メモは意味がない」とは言えません。効果が見られなかった、までです。

精神科・メンタルヘルスの定期の診察で、自分で作ったメモを持っていくと何が変わるのか。
これをまとめたレビューは、今回調べた範囲では見つかりませんでした。

### AIで準備することは

AIを使う研究は、まだ「試している段階」という感じでした。

- 患者が病院に送るメッセージについて、足りない情報をAIが聞き返せるかを試した研究（Liu ほか, 2024。米国、7つの場面を医師5人が評価）では、GPT-4に簡単な指示で聞き返させると、「完全さ」はいちばん高かった一方で、「明確さ」「簡潔さ」は低めでした（指示を細かくすると、簡潔さは上がっていました）
- 電子カルテの情報からAIに質問リストを作らせた研究（He ほか, 2026）では、多くの質問は分かりやすく妥当と評価された一方で、薬と検査値を間違って結びつけるような、もっともらしい間違いも見られました
- 一般の人がAIに医療の相談をするランダム化研究（Bean ほか, 2026。英国の1,298人）では、AI単独では病状をかなり当てられたのに、人が使うと正しく特定できたのは34.5%未満で、検索などのふだんの方法と差がありませんでした。人の側の伝え方が不完全だったり、AIが誤解を招く情報を出したりしていたそうです（出版社のプレスリリースで確認した範囲です）

最後の研究は、「症状から判断する」使い方の研究で、この記事の使い方（判断ではなく、自分の言葉の整理）とは違います。
ただ、人の側の伝え方に抜けが出やすいこと、AIはもっともらしく間違えることがあること、は覚えておいてよさそうです。

メンタルヘルスの受診前の準備にAIを使った研究は、見つかりませんでした。

### 参考：診察の時間

診察の時間がどのくらいかというと、厚生労働省の受療行動調査（令和5年）では、一般病院の外来で、診察時間が10分未満だったと答えた人が約7割でした（5分未満28.1%、5〜10分未満40.9%）。
ただし、これは一般病院の外来全体の調査で、クリニック（診療所）は入っていません。精神科の診察時間を表す数字ではないので、「だいたい短いことが多いらしい」くらいの参考です。

### ここまでで受け取ったこと

まとめると、

- 準備をすると、質問は少し増える。満足度もわずかに上がるが、不安は変わらない
- 精神科の定期の診察で、メモが何を変えるかは、まだよく分かっていない
- AIは聞き返しや整理には使えそうだけど、もっともらしく間違えることもある

という感じでした。

なので、この記事では「メモがあれば診察がうまくいく」とは言いません。
言えるのは、「言い忘れて帰る」を少し減らすための準備、くらいです。
それでも、帰りの電車で「言えばよかった」と思う回数が減るなら、私はそれで十分な気がしています。

## 03｜無料で持ち帰れる軸：伝えることを3つに絞る

ここからは研究の結論ではなく、この記事の提案です。

短い診察で全部を話すのは、たぶん無理です。
なので、最初から3つに絞ります。

1. 前回から変わったこと：よくなった／悪くなった／同じ
2. 仕事のどの場面に出ているか：会議・締切・Slackやメール・出社や在宅、など場面の名前で
3. 今日いちばん相談したいこと：1つだけ

ポイントは2つ目です。

「仕事がしんどいです」

だと、先生もどこから聞けばいいか迷う気がします。

「朝の定例で話を振られると、言葉が出てこないことが、この2週間で3回ありました」

くらいまで場面と回数があると、そこから話を広げてもらいやすいかもしれません。
（例は読者の場面として書いたもので、私の状況ではありません）

前に「職場に、心の調子をどこまで伝える？」で、職場には「仕事に何が影響しているのか」「何があると働きやすいのか」を中心に伝えたい、と書きました。
今回はその逆向きで、医療の場に「仕事にどう出ているか」を持っていく、という形です。

いちばん短い形は、こんな感じです。

```
前回から：〔少し悪くなった〕
仕事では：〔朝の会議で言葉が出ないことが、2週間で3回〕
今日相談したいこと：〔会議の多い日の、朝の過ごし方〕
```

3行なら、スマホのメモでも書けます。
診察室で、これを見ながら話してもいいし、画面をそのまま見せてもいい。

ひとつだけ、聞かせてください。

診察で話し忘れることが多いのは、①仕事のこと ②体調の細かい変化 ③聞きたかった質問 のどれですか？ コメントで番号だけでも教えてもらえたら嬉しいです。

このシリーズ「心の調子と働く」は、マガジンにまとめています。
続きを読みたい方は、フォローしてもらえると励みになります。

## 05｜定期の診察用の相談メモ

以下はこの記事の提案です。研究で効果が確かめられた型ではありません。
〔 〕の中は自分の状況に置きかえてください。例はすべて読者向けのもので、私の状況ではありません。

初めて相談に行くときのメモではなく、通院を続けている人の、いつもの診察の前に書く1枚を想定しています。

```
【〇月〇日 診察メモ】

■ 前回から変わったこと（よくなった／悪くなった／同じ）
・

■ 仕事に出ていること（場面で。1〜3つ）
・会議：
・締切・作業：
・Slack・メール：
・出社／在宅：
（当てはまらない欄は消してOK）

■ 生活のこと（気になるものだけ。眠り・食事・休みの日など）
・

■ 前回相談したこと・言われたことの、その後
・

■ 今日いちばん相談したいこと（1つ）
・

■ 時間があれば聞きたいこと
・
```

書くときのコツ（これも提案です）

- 「仕事に出ていること」は、気持ちより出来事で書く。「つらい」より「締切を1回延ばしてもらった」
- 回数が分かるものは、ざっくりでいいので数を入れる（「2週間で3回」など）
- 「前回のその後」は、先生に言われたことを試したかどうか、だけでも
- 「今日いちばん」は本当に1つにする。2つ目以降は「時間があれば」に回す

### しんどい日の3行版

全部書く気力がない日は、これだけでいいと思います。

```
前回から：〔よくなった／悪くなった／同じ〕
仕事では：〔いちばん困った場面を1つ〕
今日相談したいこと：〔1つ〕
```

それも無理なら、「最近、仕事がしんどいです」だけをスマホに書いておく、でも。
何もないよりは、診察室に入ったときの最初の一言になります。

## 06｜AIへの頼み方3つ

ここも、この記事の提案です。研究で効果が確かめられた頼み方ではありません。
02で見たとおり、AIはもっともらしく間違えることがあるので、判断はさせず、整理だけに使います。

流れは、

1. 材料を出す（AIに質問してもらう）
2. 診察で読める長さにまとめてもらう
3. 自分の言葉に戻す

の3段階です。

### 頼み方1：前回からのことを聞いてもらう

```
次の診察の前に、先生に伝えることを整理したいです。
前回の診察（〔〇月〇日〕ごろ）から今日までのことについて、私に質問してください。
質問は1回に1つにして、「仕事のどの場面で」「前回と比べてどうか」を中心に聞いてください。
病名・薬・診断についての意見は言わないでください。
10問くらい聞いたら、そこで止めてください。
```

10問も目安です。研究で決まった数ではないので、疲れたら途中で「ここまでで」と止めて大丈夫です。

「病名・薬・診断についての意見は言わないでください」を入れておくのは、AIが親切に解釈を足してくることがあるからです。
欲しいのは解釈ではなく、自分の答えなので。

### 頼み方2：診察で読める長さにまとめてもらう

```
ここまでの私の答えを、診察で先生に読んでもらう用にまとめてください。
見出しは「前回から変わったこと」「仕事に出ていること」「今日いちばん相談したいこと」の3つ。
全部で5〜7行、箇条書きで。
私が言っていないことは足さないでください。症状の解釈や、病名・薬についての意見も入れないでください。
```

5〜7行は目安です。先生が画面をぱっと見て読める長さ、くらいのつもりです。

### 頼み方3：言い方の強さを確かめる

```
今のまとめの中で、私の答えより強くなっている表現、または弱くなっている表現があれば、教えてください。
（例：私は「ときどき」と言ったのに「頻繁に」になっている、など）
直した文は出さず、どこがずれているかだけ教えてください。
```

まとめてもらうと、言い回しがきれいになる分、強さが変わることがある気がします。
「ときどき」が「頻繁に」になっていたら、先生に伝わる内容も変わってしまうので、ここだけは確かめます。
直すのは自分で。最後は、自分が診察室で口に出しても違和感のない言葉に戻しておくと、先生から質問されたときにも困らない……と思います。

## 07｜AIに入れる前のチェックリスト

健康のことは、仕事の情報とはまた別に慎重になったほうがいいと思っています。
以下はこの記事の提案で、法律や会社の規程の判断ではありません。

```
□ 会社のAIか、個人のAIか
  → 会社のAIに健康のことを入れるかは、会社のルールと自分の線引きで決める
□ 使っているサービスの、会話の保存についての説明を一度読んだか
□ 自分のフルネーム・病院名・先生の名前は入れない
□ 上司・同僚・家族の名前は〔上司〕〔同僚A〕に置きかえる
□ 社名・チーム名・プロダクト名は入れない
□ 病名・薬の名前は、入れなくてもメモは作れる（入れるかは自分で決める）
□ 「薬を変えたほうがいい？」「休んだほうがいい？」はAIに聞かない
  → それは「今日相談したいこと」に書いて、先生に聞く
□ AIのまとめに、私が言っていないことが入っていないか確かめた
```

いちばん大事なのは、下から2つ目かもしれません。
AIに判断を聞きたくなったら、それがそのまま「先生に聞きたいこと」なんだと思います。

## 08｜分岐：こういうときは

ここも研究が見つからなかった部分なので、全部この記事の提案です。

### メモを渡すと、先生がどう思うか不安なとき

最初に一言、断ってから出すと、少し気が楽かもしれません。

```
今日は話したいことをメモしてきたので、見てもらってもいいですか。
```

それでも出しにくいときは、メモは自分で見るだけにして、話すのは「今日いちばん相談したいこと」だけ、でもいいと思います。

### 話したいことが多すぎるとき

「今日いちばん」を1つ決めて、最初に言う。
残りは「時間があれば」に書いておいて、時間がなければ次回に回す。
全部を1回で話そうとしなくていい、と自分に言っておくための欄でもあります。

### メモを作る気力がないとき

作らなくていいです。
05の「しんどい日の3行版」か、「最近、仕事がしんどいです」の1行だけ。
メモ作りが診察の前の負担になるなら、本末転倒なので。
（そういう日は、AIに質問してもらう元気もない気がします、、、）【🟡確認：このかっこ書きはSena自身の感じ方として読まれます。当てはまればそのまま、当てはまらなければ削除してください】

### 仕事の話をしていいのか迷うとき

迷うなら、「今日相談したいこと」に書いてしまうのが一つです。
どこまで話すかは、先生とのやりとりの中で決まっていくものだと思います。
「仕事のことも相談していいですか」と聞いてみるのも、ありだと思います。

### 診察のあと

帰りの電車で、言われたことを1行だけメモしておく。
次の診察のメモの「前回相談したこと・言われたことの、その後」の欄に、そのまま使えます。

```
〔〇月〇日〕先生から：〔言われたことを1行〕
次までに試すこと：〔あれば〕
```

## 10｜研究で分かっていること／分かっていないこと

分かっていること

- 診察の前に、聞きたいことを準備する取り組み（主に質問シートとコーチング）は、診察中の質問の数を少し増やし、満足度をわずかに上げた。不安と知識ははっきりした変化なし。診察時間は全体では延びなかった（直前に行った場合のみ延長）。著者の結論は「患者への利益は限られている」（Kinnersley ほか, 2007。Cochrane のレビュー、33試験・8,244人）
- うつ病の外来患者100人での質問シートのランダム化比較試験では、患者が出した話題の数は増えなかった（Hamann ほか, 2014）
- AIに簡単な指示で、患者のメッセージの足りない情報を聞き返させると、完全さは高い一方で、明確さ・簡潔さは低めだった（Liu ほか, 2024。医師5人による小さな評価）
- AIが作った質問リストは、多くが分かりやすく妥当と評価された一方で、もっともらしい医学的な間違いも含まれていた（He ほか, 2026）
- 一般の人がAIに医療の相談をしても、病状の特定や対応の選択は、ふだんの方法と差がなかった。人の側の伝え方の抜けと、AIの誤った情報の両方が見られた（Bean ほか, 2026。プレスリリースで確認）

分かっていないこと（今回確認できなかったものを含む）

- 精神科・メンタルヘルスの定期の診察で、自分で作ったメモを持っていくと何が変わるか（まとめたレビューは見つからなかった）
- AIで受診前の準備をしたとき、伝え漏れ・診察の質・症状や治療が良くなるか（メンタルヘルスの研究は見つからなかった。一般の医療でも小規模な評価まで）
- 診察で「仕事への影響」を伝えることが、治療や働き方の調整にどうつながるか
- 日本の精神科クリニックの診察時間（公的な統計は見つからなかった）
- Cochrane のレビューの中で、精神科の試験が何本あり、そこで効果が違ったか

この記事の提案（研究の結論ではないもの）

- 伝えることを「前回から変わったこと／仕事のどの場面に出ているか／今日いちばん相談したいこと」の3つに絞る軸、05の相談メモと3行版、06のAIへの頼み方3つ、07のチェックリスト、08の分岐

⸻

## おわりに

受診の前にメモを作っても、診察が劇的に変わるわけではない。
研究を見ても、質問の数と満足度が少し上がるくらいで、それ以上ははっきりしませんでした。

でも、「最近どうですか？」に「まあ、普通です」以外の一言を持っていけるだけで、帰りの電車で思い出す「言えばよかった」は、少し減る……かもしれません。

AIは、頭の中を外に出すところまでを手伝ってもらう。
何を相談するか決めるのと、先生と話すのは、自分。
最近はそんなふうに考えています。
