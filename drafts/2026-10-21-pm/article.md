## 01｜研究で分かっていること：伝え方は「言う・言わない」の二択ではない

職場で心の不調を伝えることについての研究を見ると、
「言うか、言わないか」
の二択で扱われていないことが多いです。

2012年の systematic review（Brohan ほか。48本の研究）は、当事者の語りの研究をまとめる中で、伝え方をいくつかに分けています。

- 部分的に伝える（「病気がある」とだけ言う、など）
- 相手を選んで伝える
- タイミングを選んで伝える
- 意図せず知られてしまう

2025年の systematic review（Gnainsky ほか。職場に限らない、心の病気の開示全般についての量的研究42本）は、もう一歩進めて、伝えることと秘密にすることは反対のものではなく、別々の過程で、人は場面ごとに両方をやりくりしている、とまとめています。「選んで伝える」は、そのやりくりの方法として出てきました。

職場に絞った2023年の review（McGrath ほか。26本）でも、伝えた人の多くは上司から好意的な反応を受けたと報告する一方で、キャリアへの影響や拒絶への不安が、ためらう理由として共通していました。働く人は相手の反応を見ながら、少しずつ、相手を選んで伝えていた、とされています。

オランダの研究者による軍の調査（Bogaers ほか 2023。精神疾患のある軍人323人への一時点の調査）では、上司に伝えたかどうかは、働き続けやすさや職場でのウェルビーイングのどの指標とも有意な関連がなく、伝えたときの体験がよかった人は、ほぼすべての指標で点数が高かった、という報告もあります。

ただ、注意があります。

- 働いている人が伝えたあとどうなるかを調べた研究は、ほとんどが観察研究（アンケートや聞き取り）で、「伝えると良くなる／悪くなる」という因果は分かっていません。
- 研究はほとんどが欧米のもので、日本の職場で同じかは分かりません。
- 「病名は言わず、通院・体調とだけ伝える」ような伝え方そのものの効果を調べた研究は、今回は見つかりませんでした。

なので、研究から言えるのは「伝え方を選ぶ人は普通にいる」「伝えたかどうかより、伝えたときの体験のほうが関係していそう」くらいまでです。

## 02｜制度で分かっていること：指針は「毎回の理由欄」には答えていない

通院しながら働いている人は、2022年の国民生活基礎調査で2,326万人、働いている人の40.6%です（厚生労働省の審議会資料。病気の種類は問わない数字で、心の不調で通院している人の数ではありません）。
通院しながら働くこと自体は、珍しいことではないんですよね。

2026年4月からは、職場で治療と仕事の両立を支援することが事業主の努力義務になり、「治療と就業の両立支援指針」（令和8年 厚生労働省告示第28号）が出ています。

指針には、たとえばこう書かれています。

- 両立支援は、労働者本人から支援を求める申出があったことをきっかけに取り組むのが基本
- 症状や治療の状況などの健康情報は、健康診断で把握した場合を除き、原則として本人の同意なく会社が取得してはならない
- 定期的に短い治療が続く場合などに備えて、時間単位の年次有給休暇（労使協定を結んだ場合、年5日の範囲内）、病気休暇、時差出勤、在宅勤務などを、会社の実情に応じて導入することが望ましい

ただ、これは「本人が申し出て、主治医の意見をもとに会社が配慮を決める」という正式な手続きの話です。
ふだんの半休の申請で、理由欄に何を書くか。そこには、指針は答えていません。

もうひとつ、混ざりやすいのが休みの種類です。

- 年次有給休暇は、自治体の労働相談のページで「休暇を利用するための理由は、原則として問われることはありません」と説明されています（半休も、年休の一部として取る形が多いです）。
- 病気休暇など、会社が独自に設けている制度は、条件（理由や診断書が要るかなど）を会社ごとに決めています。

「理由は原則問われない」と説明されているのは年休の話で、会社の制度を使うときは、条件が別にあります。
時間単位の年休も、労使協定がある会社でだけ使えるもので、全員にあるわけではありません。

## 03｜問題提起：毎回は小さい。でも、何度も来る

通院のための申請は、1回1回はたいしたことがありません。
5分で終わる。

でも、通院が続くかぎり、何度も来ます。

そのたびに理由欄で止まって、
「今回は何て書こう」
と考える。

カレンダーの予定名を考える。
「午後いないの？」に、その場で返す言葉を探す。

1回は小さくても、決めていないと、毎回その場で考えることになります。
これが地味に疲れる、というのが今回の出発点です（研究で確かめられた話ではなく、この記事の見立てです）。

02の指針にも、業務上の理由で適切に治療を受けられない場合がある、と書かれています。
ただ、前のガイドライン（令和6年3月版）で例に挙がっていたのは糖尿病の通院で、心の不調の通院ではありません。

心の不調の受診については、時間などの事情より「自分で何とかしたい」といった気持ちの面の壁のほうが大きい、という国際調査もあります（Andrade ほか 2014）。
ただし症状が重い人では、事情の面の壁のほうが大きかったとも書かれています。

なので「申請が面倒だから通院が遅れる」とまでは言えません。
言えるのは、毎回の負担は小さくしておけるなら小さいほうがいい、くらいかもしれません。

## 05｜「理由の範囲」と「取り方」を、別々に一度だけ決める

ここからは、この記事の提案です。

毎回止まるのは、たぶん2つのことを同時に考えているからです。

ひとつめは、理由の範囲。どこまで言うか。

- ① 私用（理由は言わない）
- ② 通院・体調（病名は言わない）
- ③ 病名まで

ふたつめは、取り方。会社にある、どの休み方を使うか。

- 年休の半休
- 時間単位の年休（労使協定がある会社だけ）
- 病気休暇など、会社独自の制度
- 時差出勤や在宅の日の時間の調整（会社のルールの範囲で）

この2つを、別々に決めます。

範囲は、自分の線引きで決めるもの。
取り方は、会社の仕組みで決まるもの。

そして、取り方によって、範囲の決め方が少し変わります。
年休で取るなら、理由は原則問われないとされているので、①を選ぶ人もいます。
会社の制度を使うなら、その制度が何を求めているかを先に確かめる必要があります（02のとおり）。

決めたら、毎回同じ言い方を使う。
理由欄も、カレンダーも、聞かれたときの一言も、同じ範囲で。
毎回ゼロから考えないようにする、というのがいちばんの狙いです。

※「3段階」という区切りは目安で、研究が示したものではありません。①と②の間くらい、という人もいると思います。

コメントで番号だけでも教えてもらえたら嬉しいです。

## 06｜まず確かめる：取り方の分岐（この記事の提案）

一言を決める前に、どの休み方を使うかを確かめます。

### A｜年休（半休・時間単位）で取る

- 年休は、理由は原則問われないと説明されている休みです（02）。理由欄の扱いは、会社の申請画面や運用によって違います。「私用」と書いて出す人もいます。
- 時間単位の年休は、労使協定がある会社でだけ使えます。あるかどうかは就業規則か人事で確かめてください。導入している会社の割合の、最新の公的な数字は見つかりませんでした。
- 年休を通院に使い続けると、ほかの休みに使える日が減ります。それが気になるなら、Bを調べる理由になります。

### B｜病気休暇など、会社独自の制度を使う

- 30人以上の民営企業のうち、病気休暇がある企業は28.4%でした（令和7年就労条件総合調査）。会社によって、ある／ないが分かれます。
- 条件（理由の書き方、診断書が要るか、給与が出るか）は会社ごとに違います。
- 条件の中で②（通院・体調）までで足りるのか、③（病名）が要るのかを、先に確かめておくと迷いが減ります。

### C｜どれが使えるか分からない

人事や就業規則の担当に、病名を書かずに聞く文面の例です。

```
〔人事の担当〕さん

定期的な通院で、月に〔〇回〕ほど〔半日〕抜けることがあります。
こういう場合に使える休みの制度（半休・時間単位の休み・病気休暇など）があれば、
使い方と、申請のときに必要なもの（理由の書き方や書類など）を教えてもらえますか。
就業規則の該当の場所を教えてもらえるだけでも助かります。
```

※会社の制度が使えるかどうか、申請の扱いが適切かどうかの判断は、この記事ではしません。

## 07｜理由の範囲ごとの一言（この記事の提案）

〔〕は自分の状況に合わせて入れてください。病名を入れる欄は作っていません。③を選ぶ人は、自分で足してください。

### 申請の理由欄

```
① 私用
② 通院のため ／ 体調管理のための通院
③ 〔自分で書く〕
```

②の「体調管理のため」は、通院とだけ書くより少し広い言い方です。どちらでも大丈夫です。

### 上司に、前もって一言（チャットや1on1の最後など）

```
① 〔〇日〕の午後、半休をいただきます。〔〇〇〕は午前中に終わらせておきます。
② 〔〇日〕の午後は通院で半休をいただきます。定期のものなので、今後も月に〔〇回〕ほど同じ形で取ると思います。
```

②の「定期のもの」と添えるのは、毎回説明しなくて済むようにするためです。一度言っておけば、次からは①と同じ短さで足ります。

英語で上司に伝える場合

```
① I'll be taking the afternoon off on [date]. I'll wrap up [task] in the morning.
② I have a regular medical appointment on the afternoon of [date], so I'll be out. This happens about [how often].
```

（英語はもっと自然な言い方があると思うので、ふだんの自分の言い方に直してください）

### チームに（チームのチャットや朝会で）

```
① 〔〇日〕の午後は不在です。急ぎは〔〇時〕までにお願いします。
② 〔〇日〕の午後は用事で不在です。〔〇〇〕の件は〔△△さん〕に共有済みです。
```

チームには、②を選んだ人でも「用事」くらいにしておく、という分け方もあります。上司とチームで範囲を変えるのは、01の「相手を選んで伝える」に近い形です（それがよいと研究で分かっているわけではありません）。

## 08｜カレンダーの予定名（この記事の提案）

カレンダーは、思っているより多くの人に見えることがあります。
誰に何が見えるかは、会社のツールや共有の設定で違うので、一度だけ確かめておくと安心です。

予定名の例

```
・不在
・外出
・ブロック（〔〇時〕戻り）
・Personal
```

決め方のコツ

- 予定名に、病院名・診療科・「通院」を入れるかどうかは、理由の範囲と合わせる。チームに②まで伝えていないなら、入れない
- 予定の詳細（場所・メモ）にも、病院の住所や名前を入れない
- 毎回同じ予定名にする。毎回違う名前だと、かえって目立つことがある
- 戻る時間は入れておく。「いつ連絡がつくか」が分かれば、周りはだいたい困らない

⸻

## 09｜聞かれたときの返し方（この記事の提案）

「午後いないの？」

```
・はい、午後は用事で抜けます。〔〇時〕からは戻ります。
・はい、半休です。〔〇〇〕は終わらせてあります。
```

いちばん効くのは、理由より「いつ戻るか」「仕事はどうなっているか」を返すことかもしれません。聞いた側も、たいていはそれが知りたいだけなので。

「どこか悪いの？」

範囲を広げずに返す

```
・定期的なものなので、大丈夫です。ありがとうございます。
・ちょっとした用事です。〔明日〕は普通にいます。
```

広げてもいいと決めている相手なら

```
・定期的に通院していて、その日なんです。仕事には〔あまり〕影響ないので、気にしないでください。
```

心配されて、次の言葉が出ないとき

```
・ありがとうございます。何かあったら言いますね。
```

ここで話を終わらせても大丈夫、というのがこの記事の提案です。

⸻

## 10｜通院が増えたとき・上司が替わったとき（この記事の提案）

### A｜しばらく通院が増える

一時的に増えるときは、毎回の申請の前に、上司に一度だけ言っておくと、その後が楽になるかもしれません。言う中身は、05で決めた範囲のままで大丈夫です。

```
① しばらく〔〇月ごろ〕まで、〔午後の半休〕が月に〔〇回〕くらいに増えそうです。
　 〔〇〇〕の進め方は、〔前もって調整します〕。
② しばらく〔〇月ごろ〕まで、通院が〔月に〇回〕くらいに増えそうです。
　 今と同じように〔半休〕で取ります。毎回の説明は省かせてください。
```

### B｜増えた状態が続きそう／半休では回らない

毎回の休みで回すのが難しくなってきたら、「申請」から「相談」に切り替えるタイミングかもしれません。
目安の例です（研究が示したものではありません）。

- 同じ月に、予定外の調整を〔2回以上〕お願いしている
- それが〔2〜3か月〕続きそう
- 年休の残りが気になってきた

そのときに、働き方を「状況・してほしいこと・期間と見直し」に分けて短く伝える型は、『新しい上司との最初の1on1、何を聞いて何を伝える？』の04に書きました。【🔗リンクを貼る】
相談するときも、理由をどこまで言うかは05で決めた範囲のままで大丈夫です。①の人は「休みの取り方を相談したい」だけでも話は始められます。

会社として正式に両立支援を受ける道もあります。02の指針は、本人の申出から始まり、主治医の意見をもとに会社が配慮を決める流れです。使うかどうか、どこまで伝えるかは本人が決めることで、この記事では勧めも止めもしません。

### C｜上司が替わった

## 13｜研究で分かっていること・分かっていないこと・この記事の提案

研究・制度で分かっていること
- 職場での心の不調の伝え方は、「言う・言わない」の二択ではなく、部分的に・相手を選んで・タイミングを選んで伝えるものとして研究されている。
- 伝えたかどうかより、伝えたときの体験（よかったかどうか）のほうが働きやすさと関連していた、という調査がある（オランダの研究者による、軍人を対象にした1つの調査）。
- 通院しながら働く人は、働く人の約4割（病気の種類は問わない）。
- 両立支援の指針は、本人の申出から始まる正式な手続きの話。健康情報は原則として本人の同意なく会社が取得しない。
- 年休の理由は原則問われない。病気休暇など会社独自の制度の条件は会社ごと。時間単位の年休は労使協定がある会社だけ。

分かっていないこと
- 病名を言わず、通院・体調とだけ伝える伝え方の効果。
- 伝えることが仕事の結果を良くする／悪くするという因果（あるのは観察研究の関連だけ）。
- 日本の職場での研究。
- 申請の理由欄・予定名・一言の決め方を調べた研究。
- 心の不調の通院が、仕事の都合でどのくらい遅れたり中断したりしているか。
- 時間単位の年休を導入している会社の、最新の割合。

この記事の提案（研究の結論ではありません）
- 「理由の範囲」と「取り方」を分けて、一度だけ決める。
- 取り方を先に確かめる（年休か、会社の制度か）。
- 範囲ごとの一言・予定名・聞かれたときの返し方を、毎回同じにする。
- 相談に切り替える目安（回数・期間は目安）。
