# ADHDで段取りが苦手な人へ ― 仕事の「最初の一歩」をAIと一緒に決める手順と、研究で分かっていること（特性と私 #04）

> 状態：下書き（要記入5・確認2あり）。シリーズ「特性と私 #04」（#03 が未公開のため、番号の最終判断はSenaに）。有料化版（RULES 5.5／5.6 に合わせて作成）。公開前にこの状態の行ごと削除する。（2026-10-16 校閲の指摘で修正）

こんにちは、セナです。

朝、PCを開いて、Slackとメールをひととおり見る。
やることは分かっている。
資料を作る、返信を書く、来週の会議の準備をする。

なのに、

「で、何からやる？」

で止まって、気づいたら30分たっている。

そういう朝がある人に向けた記事です。
「やる気がない」わけではなくて、「最初の一歩」が決まらないまま時間がたってしまう人が、AIを使って頭の中を外に出し、最初の一歩を自分で決めるやり方の話です。

この記事で分かること

- 段取り・着手の難しさとADHDについて、研究で分かっていること・いないこと
- 「最初の一歩」を3つの質問で外に出す考え方（無料部分）
- そのまま使えるAIへの頼み方、止まり方別の分岐、AIに渡す前と後のチェックリスト（有料部分）

## 01｜「何から手をつければいいか」で止まる

私はADHDの診断を受けています。
知能検査の記事でも書きましたが、新しいことを理解したり、初見の問題を考えたりするのは得意なほうです。
一方で、苦手なのは、コツコツ正確に続けることと、頭の中を外に出すこと。

段取りって、たぶんこの「頭の中を外に出す」ことの連続なんですよね。
何があるかを書き出して、順番をつけて、最初の一つを決める。
頭の中では分かっているつもりでも、外に出さないと、順番も最初の一つも決まらない。

ただ、先に書いておくと、私は「ADHDでそれほど困っていない」と思っています（部屋は片付けられないけど、困ってはいない）。
なので、この記事は「ADHDだから段取りができない」という話ではありません。
困り方は人によってかなり違うし、今まさに困っている人の大変さを小さく言うつもりもありません。

じゃあ、研究では、段取りや着手の難しさについて何が分かっているのか。
少し調べてみました。

⸻

## 02｜研究で分かっていること・分かっていないこと

### 分かっていること

まず、ADHDと「実行機能」の話から。
実行機能は、計画する、切り替える、やりかけのことを止める、といった、段取りに関わる頭の働きのことです。

大人のADHDについて13本の研究をまとめたメタ分析（Boonstra ほか, 2005）では、ADHDの人と比較群の間で、抑制や切り替えなどの実行機能の課題に中くらいの差がありました（効果量 d=0.62〜0.89）。
ただ、実行機能ではない課題（単語の読み上げなど）でも、同じくらいの差がありました。
著者の結論は、「大人のADHDの難しさは、実行機能だけに限られないかもしれない」です。

次に、先延ばし。
大学生54人で、ADHDの傾向と先延ばしの関係を調べた研究（Niermann & Scheres, 2014）では、不注意の傾向が強い人ほど、日常の先延ばしが強い傾向がありました（相関 r=0.51）。
多動や衝動性の影響をのぞいても残ったのは、不注意との関係だけでした。
一方で、勉強の課題を先延ばしするかを観察した測り方では、関係は見られませんでした。

そして、「始められない」への手がかりになりそうなのが、if-then プラン（実行意図）です。
「〇〇の場面になったら、△△をする」と、場面と行動を前もって決めておくやり方で、94の検証をまとめたメタ分析（Gollwitzer & Sheeran, 2006）では、目標の達成に中〜大の効果がありました（d=0.65）。
「始められない」問題への効果は d=0.61、「途中で脱線しない」ことへの効果は d=0.77 でした。

最後に、AI。
ADHDの人がAIをどう使っているかの研究は、まだ「使っている人がどう語っているか」を集めた段階でした。

- ChatGPTをふだん使っているADHDの大人13人の、7日間の日記と面接の研究（Pinto ほか, 2025）では、頭の中のものを一気に外に出す、始めるきっかけをもらう、課題を小さく分ける、といった使い方が語られていました
- Reddit のADHDのコミュニティの147スレッドを分析した研究（Tazike ほか, 2026）では、AIは「始めるための足場」として使われていて、投稿者はAIを「自分の代わりに決めるもの」ではなく、「自分で選んで直す土台」として語っていました
- 61のニューロダイバージェント（ADHDや自閉スペクトラムなど）のコミュニティの投稿を分析した研究（Carik ほか, 2025）では、AIの使い方が20通り見つかった一方で、「定型発達向けすぎる返答」や「頼りすぎ」への懸念も挙がっていました

### 分かっていないこと・注意点

- 実行機能の研究は、検査室での課題の「平均の差」です。ADHDの人みんなに当てはまるわけではないし、仕事の段取りの困りごとを直接測ったものでもありません。2005年と、少し古い研究です
- 先延ばしの研究は、診断を受けた人ではなく、ADHDの傾向がいろいろな大学生54人（ほとんどが女性）の研究です。著者も「予備的な結果」と書いています。相関なので、不注意が先延ばしの原因とまでは言えません
- if-then プランのメタ分析は、ADHDの大人を対象にしたものではありません。また、著者たちの解説では、場面と行動をあいまいに決めると効果が出にくい、とも書かれています
- AIで段取りや着手が「良くなるか」を比べた研究は、今回調べた範囲では見つかりませんでした。3本とも、使っている人の語りを集めた研究です
- AIはもっともらしく間違えることがあります。AIの研究でも、そこは投稿者自身が警戒していました

まとめると、

- 段取りや着手の難しさは、ADHDと関係がありそう。でも、全員に同じように出るわけではない
- 「いつ・何をきっかけに・何をするか」を先に決めると、始めやすくなる、という研究はある（ADHDの大人での研究ではない）
- AIは「始めるための足場」として使われている。でも、効果はまだ確かめられていない

という感じでした。

なので、この記事では「AIを使えば段取りができるようになる」とは言いません。
言えるのは、「頭の中を外に出して、最初の一歩を自分で決める」ところを手伝ってもらう、くらいです。

## 03｜無料で持ち帰れる軸：「最初の一歩」を3つの質問で外に出す

ここからは研究の結論ではなく、この記事の提案です。

止まっているとき、頭の中では「全部」が同時に鳴っている気がします。
なので、全部を整理しようとせず、次の3つだけに答えて、外に出します。

1. これは、何ができたら「終わり」？（終わりの形）
2. 最初の5分で、何をする？（いちばん小さい一歩）
3. いつ、何をきっかけに始める？（if-then の形にする）

ポイントは3つ目です。

「資料を作る」

だと、たぶんまた止まります。

「Slackを見終わったら、資料のファイルを開いて、見出しだけ3つ書く」

くらいまで、きっかけと行動が決まっていると、少し始めやすくなるかもしれません。
（例は読者の場面として書いたもので、私の状況ではありません）

02の if-then プランの研究者たちの解説に、「場面と行動をあいまいにすると効果が出にくい」とあったので、そこを借りています。
5分も目安で、研究で決まった数字ではありません。

この3つは、紙でもスマホのメモでもいいし、AIに「私に質問して」と頼んで、聞いてもらいながら答えてもいい。
私がAIによく頼むのは「私に質問して」なんですが、理由は、自分で分かっているつもりのことも、「なんで？」と聞かれると意外に答えられないからです。
段取りも、たぶん同じです。

ひとつだけ、聞かせてください。

仕事で止まりやすいのは、①始めるとき ②途中で別のことに気を取られるとき ③やることが多すぎて選べないとき のどれですか？ コメントで番号だけでも教えてもらえたら嬉しいです。

「特性と私」は、マガジンにまとめています。
続きを読みたい方は、フォローしてもらえると励みになります。

## 05｜AIへの頼み方4つ（コピー用）

以下はこの記事の提案です。研究で効果が確かめられた頼み方ではありません。
〔 〕の中は自分の状況に置きかえてください。

流れは、

1. 頭の中を全部出す
2. 質問してもらう
3. 最初の一歩を1つに絞る
4. if-then の形にする

の4段階です。全部やらなくても、1だけ、2だけでも使えます。

頼み方1：頭の中を全部出す

```
今から、今日やらないといけないことを思いつくまま書きます。
順番も粒度もばらばらですが、整理しなくていいので、まず全部受け取ってください。
受け取ったら、私が書いたものを箇条書きで並べ直すだけにしてください。
足したり、優先順位をつけたりはまだしないでください。

〔ここに全部書く〕
```

「まだ優先順位をつけないで」を入れるのは、AIが親切に全部決めてくれようとするからです。
決めるのは、3のところで自分で。

頼み方2：質問してもらう

```
今の一覧について、私に質問してください。
質問は1回に1つにして、「何ができたら終わりか」「締切はいつか」「誰が待っているか」を中心に聞いてください。
5問くらい聞いたら、そこで止めてください。
```

5問は目安です。疲れたら途中で「ここまでで」と止めて大丈夫です。

頼み方3：最初の一歩を1つに絞る

```
ここまでの私の答えをもとに、今日の「最初の一歩」の候補を3つ出してください。
それぞれ、5分以内でできる大きさにしてください。
どれを選ぶかは私が決めるので、おすすめは言わなくて大丈夫です。
```

候補を出してもらって、選ぶのは自分。
ここを渡してしまうと、たぶん「AIが決めたから」になって、私の場合は続かない気がします。【🟡確認：この一文はSena自身の感じ方として読まれます。当てはまればそのまま、当てはまらなければ削除してください】

頼み方4：if-then の形にする

```
私が選んだ最初の一歩は〔選んだもの〕です。
これを「〇〇したら、△△する」の形の1文にしてください。
「〇〇」は、今日の私の予定の中で実際に起きること（会議が終わったら、Slackを見終わったら、など）にしてください。
```

できた1文は、付箋でもカレンダーの予定名でもいいので、目に入るところに置いておきます。

## 06｜分岐：止まり方別

ここも、研究が直接示したものではなく、この記事の提案です。

始められないとき
→ 頼み方3と4だけ使う。「最初の5分」をもっと小さくして、「ファイルを開く」「件名だけ書く」まで下げる。

途中で別のことに気を取られるとき
→ 気になったことを、その場で頼み方1のチャットに1行だけ書いて、元の作業に戻る。後でまとめて見る。
（Pinto ほか, 2025 の研究で、頭の中のものを外に出してから作業に戻る使い方が語られていました。効果を確かめた研究ではありません）

抜け漏れが出るとき
→ 1日の終わりに、頼み方1の一覧をもう一度見て、「終わった／明日に回す／もうやらない」に分けてもらう。分けるのは自分で決めて、AIには並べ直しだけ頼む。

多すぎて選べないとき
→ 頼み方2の質問に「誰が待っているか」を必ず入れる。待っている人がいるものから、最初の一歩を選ぶ。
それでも選べないときは、選べないこと自体を、上司との1on1で相談する話題にしてしまうのも一つです。

調子そのものが落ちていて、段取り以前に手が動かないとき
→ この記事の範囲を超えるかもしれません。無理に段取りを組まず、休むことや、主治医への相談も選択肢に入れてください。

## 07｜AIに渡す前・渡したあとのチェックリスト

以下はこの記事の提案で、会社の規程や法律の判断ではありません。

```
渡す前
□ 会社のAIか、個人のAIか（会社のルールで、入れていい情報が違う）
□ 社名・顧客名・プロダクト名・同僚の名前は入れない、または〔顧客A〕などに置きかえる
□ 「何を優先するか」「誰に何を送るか」は、自分で決めるところとして残す

渡したあと
□ AIが一覧に、私が言っていないタスクを足していないか
□ 締切や相手の名前が、元のメールやSlackと合っているか
□ メールやSlackを送る前に、自分で一度読んだか
□ 「今日の最初の一歩」を選んだのは自分か
```

いちばん大事なのは、最後の1つかもしれません。
AIに出してもらうのは候補まで。選ぶのは自分。
前に「AIに渡す仕事、渡さない仕事 #01」で、AIに渡すかどうかは「間違いに気づけるか」で決める、と書きました。段取りも同じで、AIの出した順番が変でも気づけるように、最初の一歩だけは自分で選んでおく、という考え方です。

## おわりに

段取りが苦手なのは、気持ちの問題というより、頭の中を外に出す手前で止まっているだけ、なのかもしれません。
研究を見ても、AIでそこが良くなるとまでは、まだ言えませんでした。

でも、「で、何からやる？」で30分止まる朝が、10分になるなら、それで十分な気がしています。

AIには、頭の中を外に出すところと、候補を出すところまで手伝ってもらう。
最初の一歩を選ぶのは、自分。
最近はそんなふうに考えています。
