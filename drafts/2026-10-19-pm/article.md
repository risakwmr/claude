## 01｜研究で分かっていること：辞め方には「型」がある

辞め方そのものを調べた研究があります。

Klotz と Bolino の2016年の論文（Journal of Applied Psychology、4つの研究からなる査読論文）です。
最近辞めた人の話から、辞め方を7つの型に分けています。
（型の中身と結果は、論文の抄録と、英国心理学会（BPS）や米国の人事団体（SHRM）の紹介記事で確かめたものです。原著の本文は読めていません）

この記事に関係する型は、このあたりです。

- 手順どおり：対面で伝え、退職届を出し、理由も説明し、ふつうの予告期間を置く
- 形式的：手順は同じだけど、理由を説明せず、短く事務的に済ませる
- 感謝して去る：感謝を伝え、引き継ぎなどで負担を減らそうとする
- 経過を共有：辞めるまでの流れ（たとえば大学院への出願）を、上司が前から知っていた
- 避ける：上司と直接話さず、人事などの第三者や、週末のメッセージで伝える
（ほかに、関係を断つような敵対的な辞め方と、衝動的な辞め方があります）

紹介記事では、いちばん多かったのは「手順どおり」の型だったそうです。
理由を説明しない「形式的」な辞め方も、珍しくなかったようです。
（型ごとの割合は、紹介記事どうしで数字が合っていないので、ここでは出しません）

上司の反応は、
「手順どおり」「感謝して去る」「経過を共有」は受け止めが比較的よく、
「避ける」「関係を断つ」「衝動的」は否定的に受け取られた、と紹介されています。
理由を言わない「形式的」な辞め方も、上司には否定的に受け取られやすかった、とも。
経過を共有していた場合は、上司の肯定的な感情が否定的な感情を上回っていた、と紹介されています（BPSの紹介記事）。

もうひとつ、個人的に大事だと思ったところ。

関係を断つような辞め方や衝動的な辞め方をした人は、上司からの不当な扱いや不公平感をより多く報告していた、と紹介されています。
辞め方は本人の性格だけで決まるものではなく、それまでの上司や会社との関係の結果でもある、というのが論文の主張です。

共著者の Bolino は、理由を言わない辞め方について「従業員は、理由を率直に話すのは賢明でないと判断しているのだろう」という趣旨のことを話しています（SHRMの記事内の引用）。

……言わない人にも、言わない理由がある。
それはそうだよな、と思いました。

## 02｜でも、研究で分かっていないことのほうが多い

この研究から言えないことも、はっきりさせておきます。

- 理由を「どこまで詳しく」言うか（体調やメンタルヘルスのことまで言うか）は、調べられていません。比べているのは「理由を説明する／しない」に近いものです。
- 測っているのは上司の「感情」で、BPSの紹介記事では、仮想場面の実験の結果だと書かれています。その後の推薦・紹介・関係が続いたかは、測っていません。
- なので、「辞め方で評判やキャリアが決まる」とは言えません。「理由を全部話すのが正解」という研究でもありません。
- 日本の職場や、リモート中心の働き方は、対象として確認できていません。

じゃあ、体調やメンタルヘルスが理由で辞めるとき、理由をどこまで伝えるか、を調べた研究はあるのか。

今回調べた範囲では、退職の場面でそれを直接調べた研究は見つかりませんでした。

職場でのメンタルヘルスの開示をまとめた systematic review（McGrath ら 2023、Brohan ら 2012）はあります。
ただ、これは在職中（採用の前や、働いている間）の開示の研究で、辞めるときの場面は扱われていません。
場面が違うので、その結果をそのまま退職に当てはめることはできません。

（在職中に、心の調子をどこまで伝えるかは「職場に、心の調子をどこまで伝える？」で書きました。今回は、辞めるときの理由に絞ります）

## 03｜問題提起：範囲を決めずに面談に入ると、だいたいどちらかになる

「なんで辞めるの？」
と聞かれたとき。

聞かれるままに、体調のことも、配慮のことも、全部話してしまう。
あるいは、何も言えずに「一身上の都合で……」と黙ってしまって、気まずくなる。

さらに、
「何か変えられることがあるなら、言ってほしい」
と言われたとき。

その場で「……じゃあ、少し考えます」と返してしまう。
本当は、持ち帰ってから考えたかったのに。

これ、どちらも、理由の範囲を先に決めていないから起きる気がしています。

## 05｜無料で持ち帰れる考え方：理由は「3段階」で、相手ごとに先に決める

ここからが本題です。
この記事の提案で、研究が示したものではありません。

退職の理由は、言うか言わないかの二択ではなく、3段階で考えてみる。

① 中身は言わない：「一身上の都合で」「次のことに挑戦したくて」
② 方向だけ言う：「働き方を変えたくて」「自分に合う働き方を優先したくて」
③ 具体的に言う：体調のこと、配慮をお願いしてきた経緯など

そして、相手ごとに、どの段階まで話すかを面談の前に決めておく。

- 上司には：〔①／②／③〕
- 人事（退職面談など）には：〔①／②／③〕
- 同僚には：〔①／②／③〕

上司には②、人事には③、同僚には①、のように、相手で変えて大丈夫です。
全員に同じ説明をしなくてもいい。

それと、もうひとつ。
理由をどこまで言うかと、感謝や引き継ぎの話は、別にできます。
①を選んでも、「お世話になりました」「引き継ぎはこう考えています」は言える。
（研究で上司の受け止めがよかったと紹介されている型には、「感謝して去る」もありました。ただ、これは理由の詳しさを比べた結果ではありません）

一度伝えたことは、あとから引っ込めにくい。
だから、決めてから話す。
少なくとも、聞かれたその場で決めないほうがいいのかもしれません。

## 06｜伝える前に：就業規則と雇用契約書で確かめること

まず、公的な資料に書いてあることから。

厚生労働省の「モデル就業規則」（令和7年12月版）では、退職に関する事項は、就業規則に必ず書く事項のひとつです（常時10人以上の労働者がいる事業場には、就業規則の作成・届出の義務があります）。
退職の規程例の一部「退職願を提出して＿＿日を経過したとき」は、日数が空欄です。何日前に申し出るかは、会社ごとに決めている部分があります。

民法にも退職の申し出についての定めがあり、就業規則との関係は説明によって書き方が分かれています。この記事では判断しません。
外資系の場合も、「別のルール」とも「どこでも同じ」とも決めつけずに、まず自分の雇用契約書と就業規則を読む。
分からないところは、人事か、都道府県労働局の総合労働相談コーナーへ（茨城労働局のQ&Aなどで案内されています）。

ここからは、この記事の提案です。確かめる項目はこのあたり。

```
就業規則・雇用契約書で確かめること
・退職の申し出は、何日（何か月）前までと書いてあるか
・申し出の方法は決まっているか（退職届の様式、システムでの申請、誰に出すか）
・最終出社日と、退職日（籍がなくなる日）は分けて考えられるか
・残っている有給休暇の扱いはどこに書いてあるか
・退職後も守る約束（秘密保持、競業など）が契約書に書かれていないか
　→ 書かれていたら、中身の判断は人事か専門家に。ここで自分で解釈しない
・会社の貸与物（PC、カードなど）の返し方
```

## 08｜伝える順番の分岐（この記事の提案）

ここは研究が示したものではありません。会社の規程に順番が書いてあれば、そちらが優先です。

上司が先か、人事が先か
→ 上司が先、が一般的だと思います（会社の手順が優先）。研究で紹介されている「避ける」型（第三者経由で伝える）は、上司に否定的に受け取られやすかったので。
→ 先に人事に連絡する手順の会社もあるので、06で確認。

上司と話しやすい場合
→ 1on1の最初に「今日は大事な話があります」と言って、伝える
→ 理由は、07のメモで決めた段階まで

上司と話しにくい場合（関係が難しい、言うと怖い）
→ 研究でも、関係を断つような辞め方は、それまでの上司との関係（不当な扱い・不公平感）とつながっていた、と紹介されていました。話しにくいのは、自分だけのせいではないかもしれません
→ 人事に、上司に伝える前に相談できるか、何が上司に伝わるかを先に聞く
→ 上司に伝える場は、短く、事実だけ（理由は①でもいい）
→ 体調がかなりしんどいときは、無理に対面にこだわらなくても大丈夫です

リモート中心で、対面で会う機会がない場合
→ いきなりSlackやメールで「辞めます」と送るより、まず「話したいことがあるので、15〜30分ください」とだけ送って、ビデオ通話で伝える（時間は目安です）
→ 話したあとに、内容をメールで送って記録を残す（退職届の出し方は会社の手順に従う）

経過を共有したい場合（転職活動を上司が知っている、など）
→ 研究では、経過を共有していた場合、上司の肯定的な感情が否定的な感情を上回っていた、と紹介されています
→ ただ、転職活動中であることを先に言うかどうかは、職場によってかなり事情が違います。言わなかったからといって、悪いことをしたわけではありません

## 09｜理由の言い方3段階 × 相手ごとの文例（この記事の提案）

言い回しは自分に合わせて変えてください。〔 〕は置きかえ。
（どれも文例です。私が実際に言った言葉ではありません）

上司に

```
①中身は言わない
「本当にお世話になりました。
一身上の都合で、〔最終出社日〕で退職したいと考えています。
引き継ぎは、〔　〕から始めたいと思っています」

②方向だけ言う
「自分に合う働き方を優先したいと考えて、退職を決めました。
これまで相談に乗ってもらって、ありがとうございました」

③具体的に言う
「体調のことで、これまで〔在宅勤務など〕の相談をしてきました。
今の働き方を続けるのは難しいと考えて、退職を決めました。
配慮してもらったことには、感謝しています」
```

人事に（退職面談など）

```
①「理由は、一身上の都合です。手続きで必要なことがあれば教えてください」
②「働き方を変えたい、というのが一番の理由です」
③「体調のことがあり、働き方を変えたいと考えました。
　　この話は、〔上司まで／人事の中だけ〕にしてもらえると助かります」
```

同僚に

```
①「〔最終出社日〕で退職することになりました。次のことに挑戦します」
②「働き方を変えたくて、退職することにしました」
③ は、同僚には言わなくても大丈夫です（言いたい相手にだけ）
```

英語の職場向け

```
① "I wanted to let you know that I've decided to leave the company.
    My last day would be around [date], following the notice period in my contract."
② "I've decided to move on, mainly because I want to work in a way that fits me better."
③ "As you know, I've been working with some accommodations for my health.
    I've decided that a different working environment would be better for me."
・感謝："I really appreciate your support over the years."
・引き継ぎ："I'd like to make the handover as smooth as possible. Here's what I'm thinking."
```

（英語は、ふだんの自分の言い方に直して使ってください。英語のメールを整えるのにAIを使うのも、ひとつの手です）

## 10｜引き止め・カウンターオファーへの返し方

### 研究で分かっていること

- 会社員について、カウンターオファー（条件を良くするから残って、という提案）を受けて残った人のその後を追った査読済みの研究は、今回見つかりませんでした。
- よく見る「受けた人の8割は半年以内に辞める」のような数字は、研究の数字ではありません。「受けても結局辞める」とも「受ければ定着する」とも、研究からは言えません。

### この記事の提案

引き止めは、受けるか断るかより先に、「その場で返事をしない」を決めておく。

その場で返事をしない一言

```
・「ありがとうございます。ただ、かなり考えて決めたことなので、今日はお返事できません」
・「お気持ちはうれしいです。少し時間をいただいてもいいですか」
```

断る一言（辞める気持ちが変わらないとき）

```
・「ありがとうございます。ただ、気持ちは変わらないので、この方向で進めさせてください」
・「条件の問題ではなくて、自分の働き方の問題なので、決めたとおりにしたいです」
・（理由の段階を上げたくないとき）「理由はさっきお話しした範囲で、これ以上は控えさせてください」
```

「考えたい」と言うとき（残ることも本当に考えたいとき）

```
・「〔日付〕までに、お返事します」と、期限を自分から言う
・「考えるために、具体的に何が変わるのか、書面かメールでいただけますか」
・考える間も、06で確かめた申し出の期限は動かないことがあるので、そこは確認しておく
```

英語の職場向け

```
・"Thank you, I really appreciate it. I've thought about this carefully, so I can't give you an answer today."
・"I appreciate the offer, but my decision is final. I'd like to move forward as planned."
・"Could I get back to you by [date]? It would help if you could share the details in writing."
```

体調や働き方が理由のとき、「配慮するから残って」と言われることもあるかもしれません。
そのときも、何が変わるのかを書面でもらってから考える、で大丈夫です。

※残ることを選ぶのも、断るのも、どちらも自分で決めていいことです。この記事はどちらも勧めません。

## 11｜最終出社日までの動き（この記事の提案）

期間の区切りは入れていません。会社と自分の状況で決めてください。

伝えた直後
- 話した内容（最終出社日、退職日、引き継ぎの方針）を、上司にメールで送って記録を残す
- 同僚に伝えるタイミングと、誰から伝えるかを、上司と決める（自分から言う前に確認）

引き継ぎ
- やっていることの一覧と、それぞれ誰に渡すかを書き出す
- 資料の場所、進行中のやりとり、関係者の連絡先をまとめる
- 自分がいなくなったあとに聞かれそうなことを、先に書いておく

同僚へのあいさつ

```
・「〔最終出社日〕で退職します。今まで本当にありがとうございました。
　引き継ぎは〔　〕さんにお願いしています」
・"My last day here will be [date]. Thank you so much for everything.
　[Name] will be taking over [work]."
```

最後に、関係を保つ一言（言いたい相手にだけ）

```
・「もしよければ、これからもつながっていてください」
・"I'd love to stay in touch."
```

辞め方がその後の関係に影響するかは、研究では分かっていません（13にまとめています）。
なので、最後のあいさつは「あとで得をするため」というより、自分が気持ちよく出るため、くらいに考えておくのがいいのかもしれません。

⸻

## 12｜伝える前に、AIで理由の範囲を整理する頼み方（この記事の提案）

注意：社名・人の名前・社内の資料や就業規則の本文は、そのまま貼らないほうが安全です（会社のルールがあれば、それに従ってください）。AIは「辞めるべきか」や法律の答えを出すためではなく、自分が何をどこまで話したいかを整理するために使います。

私はAIに「私に質問して」とよく頼みます。
自分が理解しているつもりのことも、「なんで？」と聞かれると意外に答えられないので。
退職の理由も、たぶん同じだと思います。

```
頼み方1：私に質問して
退職を伝える前に、理由をどこまで話すかを整理したいです。
私に質問して。質問は1回に1つ、全部で5つまで。
最後に、上司・人事・同僚それぞれに、
①中身は言わない ②方向だけ言う ③具体的に言う
のどれが私の考えに近いか、まとめて。決めるのは私です。
```

```
頼み方2：引き止めの練習
私が退職を伝えたあと、上司として、引き止めの言葉を1つずつ言って。
私が返したら、次の言葉に進んで。全部で3回まで。
最後に、私がその場で返事をしてしまいそうだったところを教えて。
辞めるか残るかの判断はしないで。
```

⸻

## 13｜研究で分かっていること・分かっていないこと・この記事の提案

研究で分かっていること
- 辞め方には型がある（Klotz & Bolino 2016）。理由を説明しない形式的な辞め方や、上司を避ける辞め方は、上司に否定的に受け取られやすく、経過を共有していた場合は肯定的な感情のほうが上回っていた、と紹介されている（紹介記事で確認。原著本文は未確認。上司の反応は仮想場面の実験）。
- 関係を断つような辞め方は、それまでの上司との関係（不当な扱い・不公平感）とつながっていた、と紹介されている。
- 2022年の論文（König ら）は過去の研究をまとめて、退職面談で話した理由と、あとで聞いた理由はあまり一致しなかった、という結果が古くから報告されていると書いている。本当の理由を全部は言わない人は珍しくない、ということ。ただ、だから言わなくていい、とも、言うべき、とも言えない（時間がたって考えが変わった、聞く人が違った、ということもありえる）。
- 在職中のメンタルヘルスの開示は、偏見への予想、職場の支援、タイミングや相手などに左右される、と整理されている（主に McGrath ら 2023。Brohan ら 2012 も）。どちらも退職の場面は扱っていない。
- カウンターオファーの研究で近いのは米国の研究大学の教員のもの（White-Lewis ら 2025）だけで、その時点で残ったかどうかを見たもの。その後は追っておらず、会社員とは仕組みも違う。
- 出戻り（一度辞めた会社に戻る人）の研究はあるが、小売の会社と医療機関で結果が分かれていて（Arnold ら 2021、Keller ら 2021）、どちらも辞め方は測っていない。

公的な資料に書いてあること
- 退職に関する事項は、就業規則に必ず書く事項。申し出の日数は、モデル就業規則の規程例では空欄で、会社が決める部分がある。
- 個別の事情は、都道府県労働局の総合労働相談コーナーで相談できる。

分かっていないこと
- 理由を「どこまで詳しく」伝えるか（体調まで言うか）で、上司の反応やその後の関係が変わるか。
- 体調やメンタルヘルスが理由で辞める人が、理由をどこまで伝えているか。伝えた場合と伝えなかった場合の違い。
- 辞め方が、その後の推薦・紹介・出戻りに影響するか。
- 会社員がカウンターオファーを受けて残った場合、その後どうなるか。
- 外資テック、日本の職場、リモート中心の働き方でのデータ。

この記事の提案（研究の結論ではありません）
- 理由は3段階（①中身は言わない ②方向だけ ③具体的に）で、相手ごとに先に決める。
- 理由の詳しさと、感謝や引き継ぎの話は、分けて考える。
- 引き止めには、まず「その場で返事をしない」。考えるなら期限を自分から言う。
- 準備メモ、伝える順番の分岐、文例、AIへの頼み方。
- 期間の目安は、あえて入れていません（リモートの声かけの「15〜30分」だけは目安です）。
