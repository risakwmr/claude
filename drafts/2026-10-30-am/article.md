会議で、自分の資料に質問が続く。

「あ、これ、ここで泣いたらまずい」

そういう、仕事中に気持ちが崩れそうで、その場にいるのがつらい人に向けた記事です。

## 01｜研究で分かっていること：職場の涙は、「どんな場面で」で見られ方が変わる、という研究がある

職場で泣くと、周りからどう見えるのか。
ここを調べた研究は、そう多くありません。

その中でよく引かれるのが、Elsbach & Bechky（2018）です。

- 北カリフォルニアの、さまざまな業界で働くフルタイムの専門職65人への聞き取り
- 聞いたのは、泣いた本人ではなく、職場で女性が泣く場面を見たことがある側
- 泣きやすい場面として、4つが挙がっている（個人的な事情／フィードバックへの反応／日々の仕事のストレス／白熱した会議）

見ていた側は、場面ごとに「こういうときは、こうふるまうもの」という台本のようなものを持っていて、

- 台本に合わない泣き方 → 本人の性格のせいにされやすい（「弱い」「プロらしくない」など）
- 台本に合う泣き方 → 状況のせいと受け取られやすい（「今、仕事が大変なんだな」など）

という傾向が報告されています。

それから、著者の一般向けの解説によると、受け止められにくかったのは、厳しいフィードバックへの反応として泣くことや、人のいる場所で数秒を超えて泣くこと。
逆に、低い評価を受けたあと「後で一人で」泣くことは、受け止められやすかったそうです。

ただ、この研究はかなり小さいです。

- 北カリフォルニアの65人への聞き取りで、日本の職場にそのまま当てはめられない
- 調べたのは女性が泣いた場面の見られ方だけで、男女を比べた研究ではない
- 「後で一人で」の部分は、論文本文ではなく著者の解説で書かれていること
- 「離れれば評価が下がらない」と保証する研究でもない

### 「涙を見せると、能力が低く見られる」は？

これもよく聞く話です。
写真の涙を消して比べた実験（van de Ven ら, 2017。3研究・合計1,042人）では、涙がある人は「温かい」と見られた一方、「能力が低い」とも見られていました。

ただ、これを確かめ直した研究（Zickfeld ら, 2018）では、1つ目の研究では同じ結果が出たものの、写真を増やした2つ目の研究では「能力が低く見られる」は小さくなって、はっきりしなくなりました。論文のタイトルは「たぶん、そうではない」です。

性別で見られ方が変わる、という実験もあります（Motro & Ellis, 2017／Pittarello & Motro, 2024）。ただ、どちらが不利になるかは研究ごとに分かれていて、言い切れる状態ではありません（詳しくは有料部分の13に）。

なので、ここで言えるのは、
「泣いたかどうか」より、「どんな場面で、どう見えたか」で受け止め方が変わる、という研究がある。
くらいまでです。

## 02｜研究で分かっていること：「抑え続ける」と「離れる」は、まだ比べられていない

じゃあ、その場で必死にこらえるのはどうなのか。

感情労働の研究をまとめたメタ分析（Hülsheger & Schewe, 2011。95の研究）では、感じていない感情を顔に出したり、感じている感情を隠したりする「表層演技」が多い人ほど、情緒的な消耗感（燃え尽きの中心にある疲れ）が強い、という関係が出ていました（ρ = .439。47研究・11,913人）。

ρは相関の強さで、0なら関係なし、1に近いほど強い関係です。.439 は、はっきりした関連と言える大きさです（著者は「強い関連」と書いています）。

ただ、ここも注意があります。

- 元の研究の多くは、ある1時点の調査。「隠すから疲れる」のか「疲れているから隠すことが増える」のかは分からない
- 対象の中心は接客などの対人サービスの仕事で、ふだんの働き方の傾向を測ったもの。会議中の数分をこらえることを調べたわけではない

それから、感情の調整のしかたと心の不調の関係をまとめたメタ分析（Aldao ら, 2010。114研究）では、「抑える」傾向だけでなく、「避ける（回避）」傾向も、不調と結びついていました。

つまり、「抑えるより、離れる方がいい」とは言えません。
職場で「その場を離れる」と「その場で抑える」を直接比べた研究は、見つかりませんでした。

その場を選んだり変えたりすることも、感情の調整のしかたの一つとして数えられてはいます（Gross, 2015）。ただ、その効果をまとめたメタ分析は見つかりませんでした（詳しくは有料部分の13に）。

## 03｜研究で分かっていること：呼吸の研究は、「練習を重ねた場合」の話

「落ち着くには深呼吸」とよく言われます。
研究ではどこまで分かっているのか。

呼吸法（ブレスワーク）のランダム化比較試験をまとめたメタ分析（Fincham ら, 2023）では、

- ストレス：12本の試験・785人で、自己評価のストレスが対照群より少し下がっていた（g = −0.35）
- 不安：20本の試験で、少し下がっていた（g = −0.32）

効果の大きさは、小〜中くらいです。

ただ、ここが大事なところで、

- どの試験も、何回か練習した結果。合計の練習時間は、試験によって80分〜5,625分とかなり幅がある
- 1回だけ、数分だけの効果は、このメタ分析では調べていない
- バイアスのリスクが低いと判定された試験は0本
- ストレスの12本のうち、半分は体の病気がある人、5本は一般の人が対象で、心の不調がある人の試験は1本だけ

なので、「その場で数分呼吸すれば落ち着く」とは書けません。

うつなどで治療中の人については、さらに分かっていないことが多いです。
心の不調がある人を対象に、ヨガの呼吸法（プラーナヤーマ）の試験をまとめたメタ分析（Mütze ら, 2025。6本・517人）では、抑うつについては有意な効果が見られませんでした。
うつの患者を対象にした試験は1本だけです。著者は「標準的な治療の代わりに使うべきではない」と書いています。

※この記事で紹介する呼吸の研究は、主に健康な人や体の病気がある人を対象にしたものです。うつなどで治療中の人に効くかどうかは、研究ではまだはっきりしていません。

## 04｜問題提起：「泣かないようにする」より、崩れそうなときの段取りを先に決めておく

ここからは研究の結論ではなく、この記事の考え方です。

仕事で強い不安や悩み、ストレスを感じる事柄がある、と答えた働く人は67.5%でした（厚生労働省「令和7年 労働安全衛生調査」。常用労働者10人以上の民営事業所の調査）。
これは「仕事中に泣きそうになった人」の割合ではありません。
でも、仕事でしんどさを抱えながら働いている人は、少なくないようです。

気持ちが崩れそうなとき、頭の中ではだいたい、

「泣いちゃだめ」
「でも、今出ていったら変かな」
「なんて言って出ればいいんだろう」

が同時に回っている……のかもしれません。

その場で一から考えるのは、かなり難しいと思います。
しかも、いちばん余裕がないタイミングで。

それなら、余裕があるときに、

1. どこへ、どう言って離れるか
2. 離れた先で、何をするか
3. どう言って戻るか（戻れないときは、誰に何を言うか）

を、先に決めておく。

「泣かないようにがんばる」とは別のところで、手を打っておく感じです。

ひとつ気をつけたいのは、「離れる」だけで終わらせないことです。
02で書いたとおり、ふだんから避ける傾向も不調と結びついている、という研究があります。
なので、この記事では「戻るところまで」を1セットにしています（これは研究で確かめた順番ではなく、研究と矛盾しにくいように組んだ、この記事の提案です）。

## 06｜無料で持ち帰れるもの：離れる・整える・戻る の骨組み

この記事の提案です。「3つ」は研究が示した数ではありません。

### 1. 離れる

場所と一言を、先に1つずつ決めておきます。
理由は言わなくても大丈夫です。

```
すみません、少しだけ席を外します。
```

これだけで十分なことが多いと思います。
オンラインなら、カメラをオフにして、チャットに同じ一文を置くだけでも。

### 2. 整える

離れた先でやることを、1つか2つ決めておきます。
たとえば、場所を変える・目に入るものを変える・ゆっくり息を吐いてみる・時計を見る、など。

落ち着ききらなくても大丈夫です。
「完全に元に戻ってから戻る」を条件にしないほうが、戻りやすいかもしれません。

### 3. 戻る

戻るときの一言も、先に決めておきます。
説明は短くていいと思います（説明の長さで周りの見え方が変わるか、を調べた研究は見つかりませんでした）。

そして、その日は戻れない、という判断も「戻る」の一つに入れておきます。
戻れないときに、誰に何を言うか。ここまで決めておくと、離れるときのハードルが少し下がるかもしれません。

⸻

ここで、読んでくれている人に聞いてみたいことがあります。

気持ちが崩れそうなとき、あなたは ①その場でこらえる ②席を外す ③あとで一人になってから、のどれに近いですか？
コメントで番号だけでも教えてもらえたら嬉しいです。

このシリーズは、マガジン「心の調子と働く」に入れています。
新しい記事が出たときに読みたい方は、フォローしておいてもらえると助かります。

## 07｜席を外すときの一言：場面別

文例は、どれも研究で確かめたものではなく、この記事の案です。
〔 〕は自分の場面に置きかえてください。

### 理由は、言っても言わなくてもいい

先に、ひとつだけ。
席を外す理由を、その場で説明する必要はないと思います。
言うなら、嘘をつかなくていい範囲の言葉を、先に選んでおくのがおすすめです。

- 理由を言わない版：「少しだけ席を外します」
- 一言だけ添える版：「少し気分がすぐれないので」

体調や心の調子のことを職場にどこまで伝えるかは、人によって、職場によって違います（『職場に、心の調子をどこまで伝える？』に書きました【🔗リンクを貼る】）。

### A｜対面の会議

```
すみません、少しだけ席を外します。〔5分〕ほどで戻ります。
```

```
Sorry, I need to step out for a moment. I'll be back in about [five] minutes.
```

発言の途中で言葉が出なくなったときは、

```
すみません、少し考えをまとめたいので、先に進めていてください。
```

```
Sorry, let me gather my thoughts for a moment — please go ahead without me.
```

### B｜オンライン会議

カメラとマイクをオフにして、チャットに一文。

```
すみません、数分だけ離席します。
```

```
Stepping away for a few minutes — back shortly.
```

自分が話す番が近いときは、

```
すみません、数分だけ離席します。私の議題は後ろに回してもらえると助かります。
```

```
I need to step away for a few minutes. Could we move my item to later in the agenda?
```

### C｜1on1

いちばん離れにくい場面だと思います。
相手との一対一なので、黙って出ていくのは難しい。

```
すみません、少しだけ時間をもらってもいいですか。〔5分〕ほどで戻ります。
```

```
Would it be OK if I took a short break? I'll be back in about [five] minutes.
```

オンラインの1on1なら、

```
すみません、少しだけ間をもらってもいいですか。カメラを切って、すぐ戻ります。
```

```
Could I take a quick pause? I'll turn my camera off for a moment and be right back.
```

続けるのがどうしても難しいときは、その場で続きの日を決めてしまう、という手もあります。

```
すみません、今日は一度ここで区切らせてもらってもいいですか。続きは〔明日〕お願いできると助かります。
```

```
Would it be alright if we stopped here for today? I'd appreciate it if we could pick this up [tomorrow].
```

### D｜自席・在宅で、Slackやメールを読んだとき

会議中でなければ、誰かに言う必要はないことが多いです。
画面を閉じて、立ち上がるだけでも「離れる」になります。

返信を急かされているときだけ、短く置いておきます。

```
確認しました。〔15分〕ほどで返します。
```

```
Got it — I'll get back to you in about [15] minutes.
```

（英語の言い回しは、もっと自然な形があると思います。相手や職場に合わせて直してください）

## 08｜離れた先でやること：手順

### 研究で分かっていること

呼吸法のメタ分析（Fincham ら, 2023）は、03のとおり「何回か練習した場合」の話です。ここでは、03に書いていない研究だけ足します。

- 1日5分の呼吸法とマインドフルネスを、28日間比べた研究（Balban ら, 2023。108人）。どの方法でも、練習の前後で気分がよくなっていた。ただ、不安やネガティブな気分の下がり方は、呼吸法とマインドフルネスで差がなかった
  - 対象は大学生が中心。比べた相手は「何もしない」ではなくマインドフルネス。小さな研究で、著者の1人に利益相反の開示がある
- 数分でできる方法を集めたレビュー（Chin ら, 2024。12研究）。呼吸だけの方法は、結果がまちまちだった。著者の1人に、関連する会社の創業者がいる（利益相反の開示あり）
- 10分以内の短い休憩で、疲れが少し軽くなる、というメタ分析（Albulescu ら, 2022）。ただ、気持ちの面で調べているのは疲れと活力だけ（仕事の成績には差なし）。気持ちが崩れそうなときの効果は調べられていない

なので、ここから先の手順は、「これをすれば落ち着く」ではありません。
離れた先で何をするか迷わないための、この記事の提案です。

### この記事の提案：離れた先でやること

時間の区切りは目安で、研究が示したものではありません。

1. 場所を変える
   - オフィスなら、トイレ・空いている会議室・廊下の端など、人の目が少ないところ
   - 在宅なら、カメラを切って、別の部屋かベランダへ
   - 先に「ここに行く」を1か所決めておく（その場で探さなくていいように）
2. 目に入るものを変える
   - 画面やスマホから目を離す。窓の外、壁、自分の手など、仕事と関係ないものを見る
3. 息を、ゆっくり吐いてみる
   - 吸うより吐くほうを長めに、数回。数え方や回数にこだわらなくて大丈夫です
   - 苦しくなる、めまいがするときは、無理に続けないでください
4. 時計を見る
   - 離れた時刻を見て、「〔5分〕たったら一度考える」と決める（目安です。長くても〔10〜15分〕くらいで一度、戻るか戻らないかを決める）
   - 戻る・戻らないを決めるタイミングを作るためで、「その時間で落ち着く」という意味ではありません

全部やる必要はありません。
1と4だけでも、「離れたまま、どうしよう」になりにくいかもしれません。

### 戻るか、まだ戻らないか

時計を見たときに、ざっくりこう分けます（これも提案です）。

- 涙は止まっていないけど、話は聞けそう → 戻る（09へ）。カメラオフのまま、聞くだけで参加する形でもいい
- まだ話を聞ける状態じゃない → もう少しだけ離れる。そのとき、チャットに一言（「すみません、もう少しだけかかります」）
- 今日はもう続けられない → 10のBへ

## 09｜戻るときの一言

### 研究で分かっていること

戻ったときの説明の長さや言い方で、周りの見え方が変わるかを調べた研究は、見つかりませんでした。
01の研究で言えるのは、場面によって受け止め方が変わることがある、までです。

### この記事の提案：説明は一言でいい

戻ったとき、長く説明しなくても大丈夫だと思います。
いちばん大事なのは、「戻りました」と「続けられます」が伝わることくらいかもしれません。

### A｜会議に戻る

```
失礼しました。続けてください。
```

```
Sorry about that — please carry on.
```

聞き逃したところを確かめたいときは、その場では聞かずに、あとで1人にだけ。

```
さっき席を外していた間に決まったことがあれば、あとで1行だけ教えてもらえますか。
```

```
Could you drop me a quick line on anything that was decided while I stepped out?
```

### B｜1on1に戻る

```
時間をもらってありがとうございました。続きをお願いします。
```

```
Thanks for giving me a moment. I'm ready to continue.
```

### C｜オンラインで戻る

カメラをオンにしなくても、チャットかマイクで一言。

```
戻りました。
```

```
I'm back.
```

### D｜あとで、上司にひとこと送る

会議や1on1を途中で外したあと、気になるなら、その日のうちに短く送っておく形もあります。
送らなくてもいいです。

```
さっきは途中で外してしまい、すみませんでした。今は大丈夫です。
〔話の途中だった件〕は、〔明日〕あらためて相談させてください。
```

```
Sorry for stepping out earlier. I'm OK now.
I'd like to come back to [the topic] [tomorrow], if that works for you.
```

### 何か聞かれたとき

「大丈夫だった？」と聞かれたときの返し方も、1つ決めておくと楽です。

- 理由を言わない版：「ちょっと立て直してました。もう戻れます」
- 一言だけ添える版：「少し気分がすぐれなくて。今は大丈夫です」

どこまで話すかは、自分で決めて大丈夫です。
聞かれたからといって、その場で全部を説明しなくていいと思います。

## 10｜分かれ道：こういうときはA、こういうときはB

### A｜その日のうちに戻れたとき

## 13｜研究で分かっていること／分かっていないこと／この記事の提案

### 分かっていること

- 職場で女性が泣く場面を見た側は、場面ごとの「台本」に合うかどうかで受け止め方を変えていた（Elsbach & Bechky, 2018。北カリフォルニアの専門職65人への聞き取り）。著者の解説によると、後で一人で泣く方が受け止められやすかった。小さな質的研究で、日本の職場にはそのまま当てはめられない
- 涙のある人は「温かい」と見られ、「能力が低い」とも見られた（van de Ven ら, 2017。3研究・1,042人）。確かめ直した研究（Zickfeld ら, 2018）では、研究1（531人）では同じ結果が出たが、写真を増やした研究2（471人）では小さくなり、有意ではなかった。著者らは「涙が能力不足のサインになると言えるだけの証拠は十分でない」とまとめている
- 性別による見られ方の違いは、実験によって向きが分かれている（泣いた男性が不利だった：Motro & Ellis, 2017。169人／人を操るために泣いたと見られた女性が不利だった：Pittarello & Motro, 2024。合計531人）。どれも動画や作った場面を見せる実験
- 感じていない感情を出す・感じている感情を隠す「表層演技」が多い人ほど、情緒的な消耗感が強かった（Hülsheger & Schewe, 2011。ρ = .439）。多くは1時点の調査で、因果は分からない
- 「抑える」傾向も「避ける」傾向も、心の不調と結びついていた（Aldao ら, 2010。114研究）
- その場を選ぶ・変えることは、感情の調整のしかたの一つとしてモデルに入っている（Gross, 2015）。ただ、よく引かれるメタ分析（Webb ら, 2012）の対象は、注意の向け方・認知の変化（捉え直しなど）・反応の調整（表出を抑えるなど）の3つで、「その場を離れる」は入っていない
- 呼吸法は、何回か練習した場合に、自己評価のストレス・不安が少し下がる傾向（Fincham ら, 2023。ストレス12本・785人で g = −0.35、不安20本で g = −0.32。バイアスのリスクが低い試験は0本）
- 1日5分・28日間の比較では、不安の下がり方は呼吸法とマインドフルネスで差がなかった（Balban ら, 2023。108人、大学生中心）
- 心の不調がある人を対象にした、ヨガの呼吸法（プラーナヤーマ）の試験では、抑うつに有意な効果は見られなかった（Mütze ら, 2025。6本・517人）
- 10分以内の短い休憩で、疲れが少し軽くなり、活力が少し上がる（Albulescu ら, 2022）。気持ちの面で調べているのは疲れと活力だけで、気持ちが崩れそうなときの効果ではない
- 仕事で強い不安・悩み・ストレスを感じる事柄がある働く人は67.5%（厚生労働省「令和7年 労働安全衛生調査」。2025年10月31日時点、8,393人の回答）。ストレスを相談できる人がいるのは94.8%で、そのうち実際に相談したことがあるのは71.2%

### 分かっていないこと

- 職場で「その場を離れる」と「その場で抑える」を比べて、どちらが心身や評価にとってよいか（直接比べた研究は見つからなかった）
- 泣いた本人が、席を外したかどうかで、その後の評価や気持ちがどう変わるか
- 日本の職場で、涙がどう見られるか（査読済みの研究は見つからなかった）
- オンライン会議・在宅勤務で気持ちが崩れそうになったときのこと
- 戻ったときの一言の長さや言い方で、周りの見え方が変わるか
- 気持ちが崩れそうなその場で、1回だけ数分呼吸したときの効果
- 「離れる → 整える → 戻る」の順番や、何分離れるのがよいか
- その場を選ぶ・変えることの効果をまとめたメタ分析（見つからなかった）
- うつのある人で、呼吸法やその場を離れることが役に立つか（研究ではまだはっきりしていない）
- 短い休憩が、疲れ以外の「気持ちが崩れそうなとき」にどう働くか

### この記事の提案（研究の結論ではないもの）

- 離れる・整える・戻るの3つを、余裕があるときに先に決めておく（04・06）
- 「離れる」で終わらせず、「戻る」（その日は戻れない、も含む）までを1セットにする（04）
- 場面別の、席を外す一言と戻る一言（07・09）
- 離れた先でやること4つと、5分・10〜15分の区切り（08。どちらも目安）
- 戻る・まだ戻らない・今日は戻れないの分け方（08・10）
- 自分用カード（11）

⸻

## おわりに

研究で言えるのは、「泣くと評価が下がる」とも「離れればいい」とも言い切れない、というところまででした。
呼吸も、「その場で数分やれば落ち着く」という話ではありません。

なので、この記事の段取りは、研究で効くと分かった方法ではありません。
いちばん余裕がないときに一から考えなくて済むように、先に決めておく、というだけのものです。

カードは、全部埋めなくても大丈夫です。
「行く場所」を1か所決めておくだけでも、次に崩れそうになったとき、迷うことが1つ減るかもしれません。

⸻
