## 01｜研究で分かっていること：受け入れにくいのは、受け手の弱さだけの問題ではないかもしれない

フィードバックは、もらえば伸びるわけではない（3分の1を超えるフィードバックで成績がむしろ下がっていた、という Kluger & DeNisi 1996 のメタ分析は、外資テック解剖 #01【🔗リンクを貼る】で書いたとおりです）。

じゃあ、厳しいフィードバックが受け入れられるかどうかは、何で変わるのか。

2026年に出たメタ分析（Zyberaj 2026）は、上司からのフィードバックの研究24本をまとめています。
よいフィードバックも悪いフィードバックも含めた研究で、上司のフィードバックの特徴と、受け手がそれをどう受け取り、受け入れ、応じようとするかには、平均して中程度の関連がありました（r = 0.36）。
中でも、伝える人が信頼できるか（専門性・誠実さなど）と、内容の質（具体的で、分かりやすく、建設的か）は、受け入れと比較的はっきり関係していました。

アメリカの製造業の従業員約400人の調査（Steelman & Rutkowski 2004）でも、信頼できる人から、質の高い内容を、配慮をもって伝えられたときほど、悪いフィードバックのあとに「改善しよう」と思う気持ちが高かった、と報告されています（これも1回のアンケートでの関連です）。

ただ、大事な注意があります。
これらの多くはアンケートでの「関連」で、因果は分かっていません。メタ分析の著者自身も、因果として解釈すべきではない、と注意しています。研究の多くはアメリカのもので、日本の研究は入っていません。
「言われ方」（配慮）については、直接調べた研究がまだ少ないです。

それでも、受け入れにくいのは「受け止め方が下手だから」だけではないかもしれない、とは言えそうです。

もうひとつ、組織心理学には昔から使われている考え方の枠組みがあります（Ilgen ほか 1979）。
フィードバックは、

受け取る → 受け入れる → 応じようと思う → 実際にどう応じるか

という別々の段階を通る、というものです。
受け取ったからといって受け入れたとは限らないし、受け入れても行動につながるとは限らない。途中で止まることもある。
（研究で確かめられた手順ではなく、考え方の枠組みとして使います）

## 02｜問題提起：受け止め方を変える前に、混ざっているものを分ける

厳しいことを言われたあと、よく聞くのは
「気にしすぎないで、次に活かそう」
というアドバイスです。

でも、言われた一言の中には、いろいろなものが混ざっていることが多い気がします。

たとえば（これは作った例です）、

「この資料、結論が分かりにくい。いつも詰めが甘いよね」

と言われたとき。

- 事実：この資料について「結論が分かりにくい」と言われた
- 解釈：相手には、結論が分かりにくく見えた
- 私への評価：「いつも詰めが甘い」

前の2つは、資料を直せば変わるかもしれない。
でも3つ目は、私という人についての言葉です。

研究では、相手の説明が失敗の原因をどこに置くか（本人の内側か、変わらないものか、など）で、傷つきや怒りの強さが変わった、という報告があります（Hareli & Hess 2008）。具体的でなく、配慮がなく、悪い結果を本人の能力ややる気のせいにする批判のあとは、怒りが強く、自分にはできるという感覚が下がった、という古い実験もあります（Baron 1988。Krings ほか 2015 での紹介で確認）。
どちらも職場の実際の上司と部下を調べたものではないので、職場でも同じとは言えません。

それと、何度も思い出してくよくよ考えること（反すう）と落ち込んだ気分は、一緒に起きやすいことも分かっています（Mor & Winquist 2002 のメタ分析。これも関連で、反すうのせいで落ち込む、とまでは言えません）。

だとすると、
受け入れる・受け入れないを決める前に、まず「分ける」。
これが今回の記事の提案です（研究の結論ではありません）。

## 04｜無料で持ち帰れるもの：その場の一言と、3つに分けるメモ

ここからは、この記事の提案です。

まず、その場で全部答えなくていい。
厳しいことを言われた直後は、受け取るので精一杯なことが多いです（01の枠組みでいうと、まだ「受け取る」の段階）。
その場では、これだけ言えれば十分だと思います。

「ありがとうございます。一度持ち帰って整理して、確認したいことがあればあらためて聞かせてください」

「すみません」だけで終わらせると、全部を受け入れたように見えることがあるので、「持ち帰る」と「あとで聞く」をセットにしておくと、ちょっと楽かもしれません。

そして、その夜か、少し落ち着いたら、言われたことを3つに分けてみる。

- 事実：何について、何を指摘されたか
- 解釈：相手にはどう見えていたか
- 私への評価：私という人についての言葉

3つ目に入ったものは、とりあえず「受け入れるかどうか、まだ決めないもの」として置いておく。
それだけでも、少し違うかもしれません。

※「その夜」「翌日」という区切りは目安で、研究が示したものではありません。しんどい日は、何もしないで寝る日にしても大丈夫です。

⸻

## 05｜その場で使う一言（この記事の提案）

言い回しは、自分と相手の関係に合わせて変えてください。

```
持ち帰る
・「ありがとうございます。一度持ち帰って、整理させてください」
・「今すぐうまく答えられないので、考えてからお返事してもいいですか」

具体例を聞く
・「どの部分のことか、一つ例をもらえますか」
・「次に同じものを出すとしたら、何があればよさそうですか」

確認の日を決める
・「〔明日〕、もう一度少しだけ確認させてもらえますか」

受け止めすぎない
・「ご指摘は〔資料の結論の部分〕について、という理解で合っていますか」
```

最後のひとつは、「全部ごめんなさい」にしないための言い方です。指摘の範囲を、相手と一緒に小さく確かめる感じ。

英語の職場向け

```
・"Thank you. Let me take some time to think this through."
・"Could you give me a specific example?"
・"What would good look like next time?"
・"Can we follow up on this tomorrow for a few minutes?"
```

英語は、ふだんの自分の言い方に直して使ってください。

## 06｜その夜の書き出しシート

### 研究で分かっていること

- 嫌な出来事を、自分の目のままではなく少し離れた視点（外から自分を見る、名前や三人称で考える）で振り返ると、その場の嫌な気持ちが小さくなる傾向があります。メタ分析は少なくとも3本あり、向きは同じです。
- ただし効果は小さめです。48研究のメタ分析（Guo 2022）で g = −0.26（小さい）。すでに経験したストレスの出来事を振り返る実験25本に絞ったメタ分析（Murdoch ほか 2023）では g = 0.19 で、研究の質から見て効果はまだ不確か、とされています。（数字の符号は論文ごとの付け方の違いで、どちらも「離れた視点のほうが嫌な気持ちが小さい」という同じ向きです）
- 恥のような「自分に向いた感情」では、怒りや恐れより効果が小さかった、という報告もあります（Moran & Eyal 2022。自分から離れて見ることだけでなく、心理的な距離全般をまとめたメタ分析）。厳しい評価のあとの気持ちには、効きにくいかもしれません。
- うつと診断された大人51人と健康な大人45人の1回の実験（Kross ほか 2012）では、うつのある人は、悲しかった出来事を離れた視点で60秒振り返ったほうが、その場の否定的な気分が低かったと報告されています。これは1回の短い実験で、治療になる・うつが良くなるという話ではありません。著者らは、離れて見るだけでなく「なぜそう感じたか」を考えることとセットで扱っています。
- 「何が起きたか」を具体的に考える練習をした人は、「なぜ自分は」と抽象的に考える練習をした人より、そのあと失敗したときの落ち込みが小さかった、という実験もあります（Watkins ほか 2008。軽い失敗の課題での結果で、参加者は女性が多く、うつ症状の低い人たちでした）。
- つらい出来事を書いたり話したりして打ち明けること（expressive writing など）の効果は、全体として小さいです（146本のメタ分析 Frattaroli 2006 で r = .075、追跡調査のある31本のメタ分析 Guo 2023 で g = −0.12）。「書けば楽になる」とは言い切れません。
- 「事実・解釈・私への評価」に分けて書くこと、三人称で書くこと自体の効果を調べた研究は、見つかりませんでした。

### この記事の提案：書き出しシート（コピー用）

上の研究のやり方を、書き出しの形に借りてきたものです。効果が確かめられたシートではありません。
三人称の欄は、合わないと感じたら飛ばしてください。

```
その夜の書き出しシート

① 言われた言葉（覚えている範囲で、そのまま）：
　「　　　　　　　　　　　」

② 事実（何について、何を指摘されたか）：
　

③ 解釈（相手にはどう見えていたか／相手の見立て）：
　

④ 私への評価（私という人について言われたこと）：
　→ これは「まだ受け入れるか決めないもの」に置く

⑤ 三人称で一行（自分の名前で）：
　「〔名前〕さんは、〔　〕と言われて、〔　〕と感じた。
　 そう感じたのは、たぶん〔　〕だから」

⑥ 明日、相手に確かめたいこと（1〜2個）：
　
```

書くときのコツ（これも提案です）
- ②は、資料・メール・Slack・会議など、具体的なものの名前で書く
- ④に入れたものを、②に書き直そうとしなくていい
- 全部の欄が埋まらなくても大丈夫。①と②だけの日があってもいい
- 書いているうちに、もっとしんどくなってきたら、そこで閉じる

## 07｜言われた中身による分岐（この記事の提案）

研究の言葉に近いのは「課題に向いた指摘／自分に向いた指摘」ですが、下の分け方そのものは研究で決められた区分ではなく、この記事の提案です。

### A｜行動・成果物への指摘が中心（シートの②が多い）

→ 08の「確かめる質問」に進む。
②の中から、次に直せそうなものを1つ選ぶ。全部を一度に直そうとしなくていいです。

### B｜考え方・人格に向いた言葉が中心（シートの④が多い）

※ここから下は、ある言動がパワハラにあたるかどうかを判断するものではありません。

まず、これは「受け止め方が下手」の問題にしなくていい、と思っています。
02で紹介した研究が示しているのは、そういう言い方は受け手に強い否定的な反応を起こしやすい、というところまでで、研究からは、言った人が悪いかどうかまでは分かりません。ただ、受け手が強く反応するのは、おかしなことではなさそうです。
（学生が動画を見て評価した実験では、丁寧な口調でも、小さなミスを大げさにするような言い方は、建設的な指摘より不公平だと評価されていました。受け手本人ではなく、見ている人の評価です。Krings ほか 2015）

できること（この記事の提案）
- ④の言葉は、翌日すぐに相手と話し合わなくていい
- ②に当たる部分があれば、そこだけ確かめる
- ④に当たる言葉が、何度も続く・仕事の話と関係がない、と感じるときは、ひとりで抱えずに誰かに相談する（「何度も」「関係がない」は、この記事が足した目安で、公的な基準ではありません）

公的な資料に書いてあること
厚生労働省は、職場のパワーハラスメントを「①優越的な関係を背景とした言動であって、②業務上必要かつ相当な範囲を超えたものにより、③労働者の就業環境が害されるもの」で、①から③の3つの要素を全て満たすもの、と説明しています。
人格を否定するような言動は「精神的な攻撃」にあたり得るとされる一方で、業務上必要で相当な範囲の指導は、パワハラにはあたらないとされています。
この記事では、ある言動がどちらにあたるかの判断はしません。

自分だけで判断しにくいときの相談先の候補
- 社内の相談窓口（人事、ハラスメント相談窓口など）
- 総合労働相談コーナー（各都道府県労働局）
- こころの耳（厚生労働省の働く人のメンタルヘルス・ポータルサイト。電話・SNS・メールの相談窓口があります）
- みんなの人権110番（法務省）
- 法テラス（相談先や制度の案内）

連絡先や受付時間は変わることがあるので、厚生労働省「あかるい職場応援団」の相談窓口のページ（https://www.no-harassment.mhlw.go.jp/inquiry-counter）と、こころの耳の相談窓口のページ（https://kokoro.mhlw.go.jp/agency/）で確かめてください。

### C｜言われた中身に、心当たりがある／ない

- 心当たりがある → ②の中で一番思い当たるものを1つだけ、08の質問で確かめる。④まで一緒に引き受けなくていい
- 心当たりがない → 相手にどう見えていたか（③）を、08の質問で聞いてみる。それでも分からないときは、信頼できる別の人に「〔資料〕のこの部分、どう見える？」と聞く

## 08｜翌日に確かめる質問と文面例（この記事の提案）

質問の例（Aのとき、Cのとき）

```
・「昨日の〔資料〕の件、どの部分のことか、もう一度教えてもらえますか」
・「一番直したほうがいいのは、どこですか」
・「次に出すとき、何があればよさそうですか」
・「よかった例があれば、見せてもらえますか」
・「〔相手〕さんには、どう見えていたか、もう少し聞いてもいいですか」
```

Slackで送る場合

```
昨日はフィードバックありがとうございました。
〔資料〕の〔結論の部分〕について、直す前に1点だけ確認させてください。
〔確かめたいこと〕という理解で合っていますか？
```

1on1で切り出す場合

```
昨日の件、持ち帰って整理しました。
〔②の事実〕については、〔こう直そうと思っています〕。
進め方がずれていないか、確認させてください。
```

英語の場合

```
Thanks again for the feedback yesterday.
Before I revise the [doc], I'd like to check one thing:
Did you mean [your understanding]?
```

文面に④（私への評価）を入れて「〜と言われた件ですが」と蒸し返す必要はない、と思っています。確かめるのは②と③だけ。

## 09｜AIを使う場合（この記事の提案・短く）

使わなくても、この記事の手順は成り立ちます。
使うなら、頼むのは「仕分けの手伝い」だけにします。

```
言われた言葉を、「事実」「解釈」「私への評価」の3つに仕分ける手伝いをして。
言われた言葉：「〔　〕」
どれが正しいか、私が悪いかの判断はしないで。
仕分けに迷うところは、私に質問して。
```

注意
- 頼むのは仕分けまで。シートの欄が埋まったら、そこでやりとりを終わりにする
- 言われた言葉が正しいか・相手が悪いかの判断を、AIに任せない
- 貼るのは言われた言葉だけ。名前や資料は〔相手〕〔資料〕のように置き換えてから貼る

AIに気持ちの話をするときの線引きは、『AIに心の話をするとき、私が決めている線引き』にも書いています。【🔗リンクを貼る】

## 10｜研究で分かっていること・分かっていないこと・この記事の提案

研究で分かっていること
- 上司のフィードバックが受け入れられるかは、伝える人の信頼性や内容の質と関連している（主にアンケート、相関）。
- 受け取る・受け入れる・行動しようと思う、は別の段階で、途中で止まりうる、という考え方の枠組みがある。
- 相手の説明が失敗の原因をどこに置くかで、傷つきや怒りの強さが変わる。具体的でなく、配慮がなく、悪い結果を本人の能力ややる気のせいにする批判のあとは、怒りが強く、自分にはできるという感覚が下がった（どちらも実験などで、職場の上司と部下の研究ではない）。
- 離れた視点で振り返ると、その場の嫌な気持ちが小さくなる傾向がある。ただし効果は小さめで、不確かさも残る。
- 書き出すことの効果は、全体として小さい。

分かっていないこと
- 厳しい一言を受けた直後に、本人が何をするとダメージが減るか（直接調べた研究は見つからなかった）。
- 「事実・解釈・私への評価」に分けること、三人称で書くことの効果。
- 「その場で持ち帰る」ことの効果。
- 日本の職場での研究。
- 「その夜」「翌日」という区切りの根拠。

この記事の提案（研究の結論ではありません）
- その場で全部答えず、「持ち帰る」と「あとで聞く」をセットで言う。
- 言われたことを3つに分け、「私への評価」はまだ受け入れるか決めないものとして置く。
- A／B／Cの分岐と、翌日に確かめるのは②と③だけ、という進め方。
- 時間の区切りは目安。しんどい日は何もしなくていい。
