# 外資テック解剖 #03 ― 転職で「持ち運べるもの」と「置いてくるもの」

> 状態：下書き（【✏️要記入】あり）。シリーズ「外資テック解剖 #03」。有料化版（無料：01〜02／有料：03〜07）。

こんにちは、セナです。

「外資テック解剖」の3本目は、「転職したとき、前の会社での強みはどこまで持ち運べるのか」です。

私は、GAFAMの1社に約5年勤めたあと、2026年に別のGAFAMへ転職し、職種も変えてマーケティング職になりました。「同じような規模の会社だから、前の経験がそのまま活きるはず」と思っていた部分と、そうではなかった部分があります。

この記事の前半（無料）では、成果が「会社が変わると動く」ことを示した研究と、そこから考えた問いを整理します。後半（有料）では、転職・異動の前後にそのまま使える「棚卸しシート」と「最初の90日の動き方」を、研究の裏づけと私の提案に分けてまとめました。

※この記事は、特定の会社を紹介・比較・批判する記事ではありません。また、医療の記事でもありません。「環境が変わるときの自分の資産の見方」の話です。

⸻

## 01｜研究で分かっていること：成果は、個人だけでなく「環境」に支えられている

2008年に、Groysberg、Lee、Nanda が Management Science に発表した研究があります（Vol. 54, No. 7）。投資銀行の「スターアナリスト」が会社を移ったあと、成果がどうなるかを追った研究です。

論文の要旨によると、

- 転職したスターアナリストは、転職直後に成果が下がり、その状態が少なくとも5年続いた
- 転職先の会社の能力が低い場合や、チームメンバーなしで一人で移った場合に、低下が大きかった
- 同程度の能力をもつ会社への転職でも、2年間は成果の低下がみられた
- より能力の高い会社への転職や、チームごとの転職では、低下はみられなかった

とされています。著者らは、成果の持ち運びやすさには、個人の能力だけでなく、会社固有のスキルや、会社がもつ能力が関わると結論づけています。

ただし、これは特定の業界（アナリスト）の、特定の期間の研究です。テック企業やマーケティング職に、同じ大きさでそのまま当てはまるとは言えません。また、私は要旨までしか確認できていません。

⸻

## 02｜問題提起：「私の実力」と「その環境で出せていた力」は、どこまで同じ？

この研究を読んで、私は次のような見方を持つようになりました。

前の会社で「できていた」と感じることのうち、どこまでが自分の中にあるスキルで、どこまでがその会社の仕組み・人・ツールに支えられていたのだろう。

これは研究から私が考えたことで、研究が直接証明していることではありません。「実力は環境次第」という意味でもありません。持ち運べる部分は確かにあります。ただ、それを「全部持ち運べる」と思い込むと、転職後に必要以上に落ち込んでしまうかもしれません。

では、移ったあとの「作り直し」は、何から手をつければいいのでしょうか。ここから先の有料部分では、研究で分かっていることと、私の提案を分けて、具体的な手順に落とします。

## 03｜研究：新しい環境への適応は、何に左右されるのか

新しい職場に移った人の適応について、70のサンプルをまとめて分析した論文があります（Bauer, Bodner, Erdogan, Truxillo, & Tucker, 2007, Journal of Applied Psychology, 92(3), 707–721）。要旨によると、

- 組織がどう迎え入れるか（組織社会化戦術）と、本人が自分から情報を取りにいくこと（情報探索）が、
- 「自分の役割がはっきりしている感覚」「自分にできるという感覚（自己効力感）」「職場に受け入れられている感覚」を通じて、
- 仕事の満足度、組織へのコミットメント、仕事の成果、辞めたい気持ち、実際の離職に影響していた

とされています。また、調査の設計（時間をおいて追ったか、一時点か）や、対象（学生から社会人への移行か、職業間の移動か）によって、関係の大きさは変わりました。

ここで私が注目したのは、「情報探索」、つまり新しい人が自分から聞きにいくこと、が適応の要因として扱われている点です。Groysberg らの研究が示した「会社に支えられていた部分」を、移ったあとに自分から作り直していく動きに近いと考えました（これも私の解釈で、2つの研究が直接つながっているわけではありません）。

※私が確認できたのは要旨までです。個々の効果の大きさは使っていません。

## 04｜棚卸しシート：「持ち運べるもの」と「置いてくるもの」を分ける

ここからは研究ではなく、私の提案です。転職や異動の前後に、次の表を埋めてみてください。書き出すだけで、「落ち込んでいる原因」が整理しやすくなります。

**A. 自分の中にあるもの（持ち運べる可能性が高い）**

| 項目 | 例 | 自分の場合 |
|---|---|---|
| スキル | 分析、資料作成、英語、文章 | |
| 判断の型 | 優先順位のつけ方、確認の順番 | |
| 学び方 | 新しいことを習得するときの手順 | |

**B. 人や仕組みに紐づいていたもの（そのままは持ち運べない可能性が高い）**

| 項目 | 例 | 自分の場合 |
|---|---|---|
| 人脈 | 「これは誰に聞けば早いか」の地図 | |
| 暗黙の了解 | 資料の粒度、会議の進め方、承認の通し方 | |
| 社内のツール・資料 | 過去事例の置き場所、テンプレート | |
| 信頼の貯金 | 「あの人に任せれば大丈夫」という評判 | |

**C. 新しい環境で作り直すもの**

| 項目 | 最初にやること（例） | 自分の場合 |
|---|---|---|
| 情報の入り口 | 質問できる相手を3人見つける | |
| 期待のすり合わせ | 上司と「最初の成果」を言葉にする | |
| 小さな実績 | 早めに終わる仕事を1つ出す | |

使い方のコツは、Aに入れたものを疑いすぎないことと、Bに入れたものを「自分の力不足」と読み替えないことです。Bは、環境が変われば一度なくなるのがふつう、と整理しておくと、落ち込みの原因を切り分けられます（これも私の提案で、効果が検証されたやり方ではありません）。

【✏️要記入：私自身の記入例を、会社が特定されない範囲で1〜2行ずつ。（ガイド：Aに入れたこと、Bに入れたこと、Cで最初にやったこと。書けないところは空欄のままでも、表そのものが役に立ちます）】

## 05｜最初の90日の動き方（研究の3つの感覚に対応させた提案）

03の研究で挙げられていた3つの感覚（役割がはっきりしている／自分にできる／受け入れられている）に合わせて、動き方を並べます。「90日」という区切りは目安で、研究が示した期間ではありません。

**役割がはっきりしている感覚をつくる**

- 最初の1〜2週間で、上司に次の質問をしてみる
  - 「3か月後に、どんな状態なら『順調』と言えますか？」
  - 「優先度が高いのは、どの仕事ですか？」
  - 「判断に迷ったとき、誰に相談するのがよいですか？」
- 返ってきた答えを、メモではなく自分の言葉で書き直して見せる（認識のズレを早く見つける）

**自分にできる感覚をつくる**

- 1か月以内に「早く終わる小さな仕事」を1つ出す。大きな成果を狙うより、成果が見える形で1つ完了させる
- Aの棚卸しで書いた「持ち運べるスキル」が使える場面を、1つ意識して選ぶ

**受け入れられている感覚をつくる**

- 週に1回、仕事以外でも話しかけられる相手を1人増やす（まず3人）
- 分からないことは、5分調べて分からなければ聞く、という自分ルールを決める（聞くことを「迷惑」と決めつけない）

**情報探索のための質問リスト**

- 「この資料やデータは、どこに置いてありますか？」
- 「この判断は、どの会議で決まりますか？」
- 「前に同じようなことをした人は誰ですか？」
- 「やってはいけないことは何ですか？」

【✏️要記入：実際にやってみて役に立ったこと、合わなかったこと。（ガイド：上司への質問、聞き方、時間のかけ方など。まだ試していなければ「これから試す」と書いて問題ありません）】

## 06｜「前の会社ではできたのに」と思ったときのチェック

落ち込んだとき、次の順で自分に聞いてみる、という使い方もできます（私の提案です）。

1. これはAのこと（スキル・判断・学び方）？それともBのこと（人・暗黙の了解・ツール・信頼）？
2. Bなら、Cのどれから作り直せる？（情報の入り口／期待のすり合わせ／小さな実績）
3. Aなら、使い方の問題か、使う場がまだ与えられていないだけか。上司に聞いて確かめられるか

「前は当たり前にできていた」と感じる多くの場面は、Bに入ることが多いはず、というのが私の仮説です（検証されたものではありません）。

【✏️要記入：実際に「前はできたのに」と感じた場面と、それがAとBのどちらだったか、今の見立て。】

【✏️要記入（任意・本人の開示判断が必要）：体調の波があるときに、環境が変わる時期をどう乗り切る工夫をしていますか。書かない場合は、この項目ごと削除してください。】

## 07｜研究で分かっていること、分かっていないこと

**研究で分かっていること**

- 投資銀行のスターアナリストでは、転職後に成果が下がり、少なくとも5年続いた。チームごとの転職や、より能力の高い会社への転職では低下がみられなかった（Groysberg ら, 2008。要旨で確認）
- 新規参入者の適応では、組織の迎え方と本人の情報探索が、役割の明確さ・自己効力感・社会的受容を通じて、満足度・成果・離職などに影響していた（Bauer ら, 2007。70サンプルのメタ分析、要旨で確認）

**分かっていないこと**

- テック企業やマーケティング職で、同じことがどれくらい起きるか（紹介した研究からは言えない）
- 04の棚卸しシートや、05の動き方が、転職後の適応を実際に助けるか（私の提案であり、検証された方法ではありません）
